# 课程作业一致性专项核查｜D001—D016

- **对象**：当前《数据结构与算法》课程 16 讲课后作业（以 `slides.py` 为内容主源），共同规范、程序实践及必要工程机制。
- **触发依据**：学生反馈指出过程记录标准不明，以及“在仓库执行”与本地运行、远程提交混淆。
- **判断边界**：记录仓库内可复查的事实与本轮处置；不把静态文本、编译成功或构建通过当作学生已理解的证据。飞书各周实际发布原文尚未取得，不宣称远程发布完全一致；已有作业变更也不追溯要求学生补交。
- **方案**：正式 A/B 作业由每次课件课后页定义；统一规范只管跨课要求；学生本地 C 编程、飞书提交，普通作业无需 GitHub push/PR。
