# 课程课件共性约定

版本：2；更新：2026-11-02。适用于本课程的课件建设与修订。目的是减少教师重复制作和学生重新识别表达方式的成本。工程检查、AI 自审、教师审阅和真实学习证据分别记录。

## 入口与职责

- 根 `AGENTS.md` 路由到 `course/`、`course/decks/`、`tools/deck/` 的作用域入口；本文件唯一维护完整共性，修订指南维护方法、情境与反例。入口与链接由检查器核对，规范变化进入影响分析与依赖指纹。
- 每讲 `README.md` 维护教学目标、范围、路径、活动预算和证据接口；`slides.py` 维护表达与页面职责；HTML 由工具生成。
- `tools/deck/` 维护共享实现、样例与检查。新 AI 会话先读本入口链、相关组件说明和本讲设计卡，无需读取全部历史讨论。
- 历史规划与个别课件做法可作参考，不自动成为当前强制规则。个人 Memo 不取代课程约定。遇到冲突要标明对象和依据，按当前任务处理。

## 六方面共性

| 方面 | 必须满足（相应情境触发） | 默认采用 | 按需选择 |
| --- | --- | --- | --- |
| 教学目标与证据 | 明确内容边界、必要先修、关键前提及最低学习证据；关键结论与输入准确 | 少数主要认知跨越、目标与活动对应 | 证明深度、扩展练习与额外证据 |
| 课程连续性 | 术语、编号与表示对应可解释；设计、资产、实际运行和达成证据分开 | 回收必要旧知，说明前后接口 | 跨学科或真实项目延伸 |
| 表达组织 | 当前任务可识别；有关联的部分名称、顺序和归属一致 | 多部分课件用公共大纲与起始页，信息从同一声明生成 | 单任务、短专题可省导航；有理由的紧凑组织 |
| 表示与视觉语言 | 图、表、公式、代码含义对应；对象、属性与状态可区分；跨表示的角色和索引对应可解释；不只靠颜色传达语义 | 基础字号层级、间距、数学渲染与公共模式 | 特殊证明图、对象布局、算法特有状态 |
| 教学交互 | 作答与核对期间，题目、条件、必要输入及待对照材料持续可访问；提示/答案对应任务；中间状态与完成语义准确 | 手动分步、上一步/下一步/重置，答案默认收起并追加；构造或转换任务呈现完成产物并解释理由 | 交互粒度、并列/上下布局、核对展开态纵向滚动 |
| 制作与验证 | 主源唯一、派生物同步；报告对应版本与范围；发现阻断问题须修订并复查；公开性遵守 AGENTS | 复用公共能力，按改动影响检查，留下绑定版本的交付审阅记录 | 新模式和局部扩展，使用后再判断是否公共化 |

“必须满足”包括专业判断事项，不等于全部可自动判断。自动检查不能证明数学正确、认知路径合理或学生已经理解。默认形式的偏离只需在设计卡或 PR 简述教学原因、影响与检查；不得以说明解除正确性、必要输入或公开性要求。

## 公共模式与适用边界

1. 大纲默认采用有序导航：序号、阶段主题、核心问题与弱化的实际页码；不再用“部分”表头配合逐行“第一部分”等标签。主题与问题承担概括与引导两种职责，应分别提供信息；如果二者近义重复，先修订部分声明。确需比较多个属性时可选表格。活动时间默认留在设计卡，部分数和页数均由认知路径决定，不能从页数换算讲授时间。
2. 部分起始页由主标题一次表达完整部分标识与主题，不输出小号分节行，也不保留空白占位。引导问题和展开范围承担不同职责。普通内容页可保留分节行定位上下文，主标题表达本页任务；两者完全重复时仅输出主标题。分节归属仍完整保留在源码元数据中，显示由公共页头渲染器决定。文字主导为默认；特殊图示仍可留在普通内容页，不强迫套入导航组件。
3. 任务工作区将必要输入、提问、提示/答案分开。展开答案后，原题、条件、图/表/初始状态和待对照代码持续保留；可以在同一工作区滚动核对，无需关闭答案或翻页取回材料。默认投影态保持清晰；已识别的核对区展开态可纵向滚动，仍检查横向溢出、可达、裁切、遮挡及无关区域异常增高。打印保留题目与输入，隐藏答案。默认可见标题和图注仍需人工检查，不能泄漏独立题答案。
4. 共用图示与播放器不统一算法概念：DFS 访问、子树完成、Dijkstra 确认分别由算法文字、图例和语义测试解释。
5. 构造、补全或转换图、树、表示等结构时，默认在答案中呈现完成后的结构，保留必要输入并解释依据；能由文字完整核对的简单关系不强制加图。结果图与文字对应相同关系数据，检查最终产物的对象、关系与方向；“存在 SVG”或文字包含边名不足以证明结果正确。

单任务课件可以没有部分声明和大纲。声明多个部分后默认采用大纲；紧凑变体在源码记录一次教学理由。组件支持的参数内变化不要求逐页审批。首版 API、使用方法和可运行样例见 [工具说明](../../tools/deck/README.md#课程公共模式)。

## 符号与核对语境

- 首次进入一般公式、证明或代码时，在当前任务附近提供必要角色及实例映射，区分真实对象、其属性、当前状态和最终结论。距离估计不直接等同于最短距离，活动标识不直接等同于时长；这些分别由对应课程解释，不统一变量名。
- 顶点名索引、整数编号和程序数组的对应要可判断。表头已明确数量含义的数值表可以保持简写，`A=0` 的编号映射也可以成立；不全局禁止“字母=数值”，不把所有代码包装成数学公式。
- 必要材料不放在会被替换的预览区。一般段落、表、代码、图及显式 `data-required-context` 子单元接受可见/可达检查；作者仍须判断材料是否完整，标签不是语义正确性的证明。
- 空白填答框可在任务仍保留时转成完整结果；同一输入的简略过程也可切换成完整过程。只有已确认不丢失必要语境的预览才可用 `data-review-replaceable` 声明替换理由；该声明不允许隐藏显式必要单元。普通问题和对照代码不能这样豁免。

## 检查与证据

| 层次 | 机械检查 | 专业判断责任 |
| --- | --- | --- |
| 结构 | ID、角色、部分归属、生成导航与源码、构建一致性 | 阶段划分及页面职责是否恰当 |
| 页头 | 最终 HTML 的主标题结构、起始页无分节行、保守的完全重复检查；浏览器 DOM 再核对 | 近义表达是否冗余、引导问题是否提供新信息 |
| 语义 | 已测输入的状态、不变量、结果与程序对照 | 论证、教材术语、边界及案例代表性 |
| 呈现 | 指定尺寸默认布局、公式、控件、核对材料可见/可达、已声明区域的裁切/遮挡探测 | 材料完整性、未声明的局部问题、后排可读性、默认文字泄漏 |
| 教学 | 记录审阅对象及依据 | 目标、活动、学习证据和实际课堂变化 |

报告分开标识静态通过、默认页面检查、完整操作检查、失败、未完成与专业补查。AI 自审和教师审阅分别归属，不改写机器原始结果。检查器保留正常与故障夹具，不能通过放宽规则或更新基准掩盖失败。公共生成一致性继续检查，同时为关键结果增加独立断言。

页头文字比较只合并空白格式、ASCII 全半角及已知章节前缀的 `·`/`：` 分隔差异；保留词间边界、运算符、其他标点和数学字母。不得用语义相似度自动删减教学内容，也不得靠 CSS 隐藏重复节点代替结构修正。

报告记录源、共享依赖、工具版本与覆盖范围。改变共享资源时按影响对象回归；全局资源改变不能排除旧课件。影响分析无法确定时保守扩大范围。

已采用公共组件的课件完整检查所有支持操作；受影响的旧 `answer-workspace` / `tree-swap` 另运行 `review-context` 定向检查，保留默认页基线。定向覆盖只包括已识别核对区的展开/收起、必要语境、布局和打印，不代表播放器步骤或整讲交互已经验证。新增核对模式应接入适配并保留正常、隐藏材料、裁切、遮挡及滚动边界故障参照。

旧课件默认页若发现溢出，可与明确基线提交在同一环境重测。仅相同页面 DOM、相同位置和相同溢出数值可记为既有发现；原始失败报告不改写。新增、加重、页面内容变化以及字体/资源等非布局失败仍阻断。此分类只支持所测布局的回归判断，不表示旧页面可用或完整交互已经通过。

新增页头检查发现基线旧页重复、而当前同一页相应检查通过时，可单列为已修复的基线页头发现；原始报告保留。当前页头失败不能归入既有布局发现，字体或资源等基线环境失败仍使对照不可用。

## 交付完成条件

任务开始时将需求对应到具体页面、预期产物、公共能力和验收方式。制作后执行机器检查、六方面 AI 内容与视觉自审、问题修订和受影响范围复查；全部新课件覆盖所有页与受支持操作，局部修订和公共改动按实际影响范围处理。

统一验证入口只产生机器结论，交付状态保持 `pending-review`。AI 完成实际自审后，用 `review.py` 记录审阅人类型、六方面判断、目标页面/操作、证据以及发现的处置与复查。工具检查记录完整性、当前内容指纹、机器报告和证据文件是否仍一致，并拒绝未决阻断问题。结构有效不能证明判断正确。

内容、规则或共享依赖变化后，旧验证和审阅记录失效；只因提交内容产生新的 commit 元数据不会使相同内容失效。最终交付可称“可供教师审阅”；教师是否审阅、课堂是否使用、学生是否理解分别需要相应证据。不得等待并未授权采集的课堂证据而阻止普通制作任务交付。

## 渐进接入与维护

- 新课件使用当前公共模式和结构信息。D014–D016 已接入；旧课件保持可构建，按实际影响修订并记录覆盖，不强迫整讲迁移。
- 局部修订检查关联内容，不因尚未迁移而强迫整讲改版；已知缺口应具体记录，受本次改动影响时重新核验。必要输入和正确性问题优先解决。
- CI 先报告，成熟检查再按维护者决定设为合并条件；不默认增加审批人数。AI 审阅不替代教师的教学判断。
- 反馈先判断影响的对象、适用边界与重复性，再决定修复内容、公共能力或检查规则，不把一次意见直接升级为全课程要求。
- 后续观察重复返修、问题定位和审阅成本，以及学生能否识别阶段、找到输入、解释关键步骤。工具自测不作为效率改善或教学效果证明。
