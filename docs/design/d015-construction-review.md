- 日期：2026-11-01；基线：`main@93d0708`。
- 临时分支：`codex/d015-topological-critical-path`。
- 目标：依赖约束 → 合法顺序 → 最早工期 → 时间余量与关键活动。

## 实施顺序

1. 固化设计卡、六活动主例和重编号独立题，保留三轮讨论及压力测试的边界。
2. 分离状态计算与 HTML 渲染，实现拓扑排序、正向最早时间和逆向最迟时间；用独立路径枚举核对。
3. 编写 C11 演示，与 Python 核对主例、变式、零时长、环及重编号。
4. 使用课程公共导航、部分起始页、任务工作区和播放器制作 HTML 初稿；页数服务于页面职责。
5. 系统检查数学、内容接口、状态语义、输入可见性、投影、阅读与打印；修订后运行全课件回归。
6. 更新资产登记并提交 PR；设计实现不登记为课堂运行或学习达成。

## 压力测试必须落实

- 拓扑输出是排位操作，不是现实活动完成；微状态与轮末不变量分开。
- 停滞说明剩余子图中存在环，不宣称所有剩余顶点都在环上。
- AOV 的活动顶点与 AOE 的事件顶点分开，验证转换未增加或遗漏先后关系。
- 编号不代表处理顺序；源汇明确给出，不以最大编号推定汇点。
- 最迟时间统一以不延长最早工期为准；按活动余量判定关键性，余量不可任意叠加。
- 线性复杂度针对时间、余量与关键活动及一条代表路径；不承诺枚举全部路径。
- 独立依赖建模小诊断与 AOE 计算分别记录；保留 8 分钟独立作答与 3 分钟反馈。

## 算法、教材与学习任务检查

- 六活动表和两种图表示使用同一主例，逐活动对核对先后关系。主例 T=10、关键 B/D/F，B=4 与 B=3 分别得到 T=9、9；共享余量、关键端点反例、环和重编号独立题均复核。
- 拓扑微状态以尚未解除的原弧核对剩余入度；只有轮次边界使用未输出前驱解释。原图不删边，输入弧、候选、输出和已完成出边扫描分别显示。
- 正向待汇总值为下界，反向待汇总值为上界；确定标记逐状态核对。有限小 DAG 的最早/最迟时间与独立路径枚举核对，再与 C 交叉检查。
- 明确活动余量、多个关键路径、资源条件和最迟时间基准；核心线性复杂度不包含输入验证、追踪快照及全部路径枚举。
- 教材 6.6.3/6.6.4、算法 6.12/6.13、选择题（15）与应用题（5）接口保留；学生页没有 CI、资产状态或工程审阅说明。公开注记不含学生个体或教师私有信息。
- 新依赖短诊断和新 AOE 计算分别承担建模与机制应用证据；8+3 分钟独立作答/反馈保持。90 分钟为活动预算，尚未排练，不从 33 页推算用时。
