## 重点内容验收

- 松弛中的 `u` 是本次新候选路径的前驱；仅在接受更短候选后更新 `parent[v]`。
- `dist[v]` 是当前找到的最好路径长度；确认后才可等同于真正最短距离。`dist[D]` 是课堂按顶点名索引的记法，D 编号为 3 时 C 程序使用 `dist[3]`。
- 确认论证明确源点、已确认集合、当前最小有限候选、首次出界边与路径终点；数值图只示意首次出界，不伪装为反证假设的更短路径。
- D014 第 22 页的 B 行矩阵、邻接项、更新前状态和题目均持续可访问；第 24 页代码与字段对照共同可访问。
- D015 区分活动与持续时间；D016 不重复已有定义，补具体记录/下标/概率/算法比较次数的映射。

## 工程验收

- 展开/收起、返回/重置、连续阅读和打印行为按教学职责核对；打印保留题目与输入，按现有策略隐藏答案。
- 浏览器检查核对实际必要单元；CSS 可见不自动等于可达或未被遮挡。
- 允许纵向滚动只适用于实际展开的已知核对区域；默认态、无关区域、横向溢出及不可达内容不因此获得豁免。
- 数值和关键结果采用独立参照；专业判断仍负责符号意义和数学论证，工具不声明证明教学有效。
- 全局样式、规则和工具变化保守扩大影响范围。D010/D013 的定向交互证据单独记录，不能冒充旧课件全交互覆盖。
- 统一检查入口及 `review.py check` 绑定当前源码与证据；共享资源变更使旧记录失效。
