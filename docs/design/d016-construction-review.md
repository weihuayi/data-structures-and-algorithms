## 必须保留的内容边界

主例：5、16、20、27、30、36、44、55、60、67、71。顺序基线从前向后；折半闭区间、向下取中点。ASL 计数为比较过的记录关键字个数，不等同 C 条件测试次数或计时。成功/失败与概率模型分别说明。分块主例静态，要求块间范围有序，不由索引最大值递增代替。哨兵技巧、闭式公式和完整动态维护作为教材深化，BST/AVL、散列、排序实现归后续讲。

## 审阅与复查

| 实际发现 | 修订 | 复查方式 |
| --- | --- | --- |
| 720p 分步演示与分块页有少量溢出 | 调整本讲数组、状态区和索引间距，保留字号与完整输入 | 两尺寸全部步骤、边界、返回/重置 |
| 小数组任务展开后过高，独立判定树答案溢出明显 | 输入与反馈左右并置，简化图注，保留完整答案树和理由 | 默认/展开及打印，独立树实际拓扑断言 |
| 术语和符号仍有精确性缺口 | 关键字明确为数据项的值；补 p_i、c_i；对应 C 的关键字数组简化 | 逐页内容自审及最终渲染复查 |
| 课后阅读文字孤行及后台制作术语进入学生页面 | 缩短阅读要求，明确自拟 4–7 个键；移去 Assignment 制作状态 | 课后页内容与投影截图 |

实现复用 CourseDeck/Section/task_workspace、tree_trace.player 和 tree_diagram.tree。新状态与视图位于 search_trace.py，样式限定 search-lesson；不增加 JavaScript 播放分支。C11 轨迹与核心代码预览同源，输入检查属于 CLI/构建阶段，不计入查询。

语义测试包含独立线性查找参照、构造/随机输入、候选不漏与严格推进、字面成本参照、成功/失败条件、精确概率、分块成员范围以及 C 对照。独立题按最终 SVG 结点与边拓扑核对，缺边和错结点故障不通过；不能用“出现 SVG 或关键字”代替正确结构。

AI 自审对象包括全部默认页面的路径/布局总览，并重点查看所有起始页、比较/更新/末态、答案展开、判定树、ASL 假设、分块索引与代码/课后命令。自动操作覆盖与 AI 视觉取样分别记录，不把取样说成全部状态逐一视觉审阅。AI 自审不写成教师已审阅，工具结果不写成学生已掌握。

最终入口为 verify.py --all --base 1d87a32 --screenshots all，随后填写实际审阅记录并执行 review.py check；机器结果、旧问题基线比较和 AI 交付状态分开保留。未验证旧课件全部交互、后排实测、实际用时或学习达成。
