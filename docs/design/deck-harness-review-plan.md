## 设计依据与边界

- 学习任务决定表示；每个可见元素提供定位、解释或反馈价值；生成同步与独立结果验收分别负责。
- [OpenAI Harness engineering](https://openai.com/index/harness-engineering/)：短入口连接分层知识，并以机械检查维持关联与有效性。
- [Anthropic 长任务 Harness 案例](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents)：明确完成条件、端到端验证和可接续记录，减少过早宣布完成。
- [AGENTS.md](https://agents.md/) 提供目录级约定实践；仓库根入口仍显式路由，避免假定每种工具都自动加载。
- [GOV.UK Table](https://design-system.service.gov.uk/components/table/) 区分信息比较和页面布局。本课程默认有序导航是结合当前认知任务作出的设计选择，不据外部案例宣称教学效果已成立。
