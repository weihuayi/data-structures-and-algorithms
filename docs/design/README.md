# 课程设计入口

- [一致性工程实施计划](deck-consistency-plan.md)：实施范围、切片、实测与待验证事项。
- [部分起始页重复页头修订](section-heading-review.md)：渲染职责缺口、失败复现与回归记录。
- [D015 建设与一致性审阅](d015-construction-review.md)：认知路径落实、压力用例、初稿修订与验证范围。

- [课件修订方法](deck-revision-guide.md)：从教学任务定位缺陷与选择修订方式。
- [旧课件布局待修记录](legacy-layout-findings.md)：一次同环境基线观测，原始失败未改写。
