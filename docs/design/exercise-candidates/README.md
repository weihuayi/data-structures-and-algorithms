## 审定要点（提取中发现的需教师裁决项）

1. **D007 与 nextval 的定位冲突**：设计卡把 nextval 列为教师注记级轻处理，但第 4 章候选含选择题 (4)（nextval）与应用题 (1)（next + nextval）。要么保留（nextval 实为考试内容，需上调处理级别），要么砍 (4)、应用题 (1) 只要求 next 部分。
2. **第 3 章选择题 (13)**：选项 D「(rear-l)%n」字符疑为 1/l 提取歧义，布置时对照纸质教材。
3. **第 4 章选择题 (3)**：串长 12 而选项 D 为 13 位数字，两种提取模式一致，疑为原书排版问题。
4. **第 5 章应用题 (5)**：16 个 Merge × 3 种合并策略，工作量大，建议减半指定小问。
5. **第 6 章选择题 (13)**：选项在文本提取中完全缺失，已渲染页面图像补全，建议对照原书复核；**算法设计题 (3)** 题干未指明带权与否，归属 BFS/最短路径有歧义，未分配。
6. **第 7 章选择题 (6)**：题干表述本身有歧义（BST 最坏 O(n) 相关）；**应用题 (6)** 的平方上标在提取中丢失，不影响题号。
7. **D012 候选偏重**：6 道选择 + 2 道应用 + 1 道算法，超出单周作业量的合理份额，草案已给出砍法（砍选择 (6)、算法 (2) 转选做）。
