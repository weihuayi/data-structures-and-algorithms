# Assignments | 课程作业共同规范

本目录维护课程作业的共同要求，以及跨多讲组织的综合计算实践任务。

- [作业规范｜面向学生](homework-guide.md)：统一的 A/B 作业、代码运行、AI 使用和提交要求。
- [校园综合计算实践（2026 秋季）](campus-computing-practice/README.md)：跨多讲的个人综合实践；学生从三个题目中任选一个，提交一份报告。教师参考实现与测试位于该任务的独立 reference/ 和 tests/ 目录。

**单讲正式 A/B 作业仍由对应课件的课后页定义**，slides.py 是具体任务主源，index.html 为受控派生物。本目录不复制或替代单讲课件中的题目。

课件中自学、挑战、选做等内容不自动成为必做；一次飞书集中收取可以涉及多次课或多个 Deck，截止时间及实际收集入口由当届教师/助教通知。Offering 只记录有真实依据的实施和公开安排，不替代课程作业题目。已发布的要求若调整须明确告知，不能靠改 Git 历史追溯追加。

学生通过飞书提交个人作业，公开 submissions/ 仅用于适合公开的独立贡献任务。助教可用 AI 辅助预检完整性、可运行性和共性错误，但真实性、理解及学习效果仍需人的专业判断。
