# Assignments

本目录承载教师已经明确形成的学习任务定义。Assignment 与学生实际 Submission 分开维护，也不要求物理归属于某一个 Deck。

一份 Assignment 可以关联一个或多个 Deck；发布时间、截止时间、提交模式等某学期运行信息由对应 Course Offering 维护。尚未确认任务边界、提交物和提交方式的练习候选不进入本目录作为正式 Assignment。

- [`homework-guide.md`](homework-guide.md)：每周作业制度（面向学生）：双层结构（书本习题 + 扩展作业）、AI 使用规范、提交规范。各周作业的具体题号维护在对应 Deck 的课后衔接页，本目录不复制。

批改约定（面向教师与助教）：助教全批，可借助 AI 预检（代码可运行性、完整性、格式），聚焦过程记录的真实性与共性错误收集；每周共性错误在下次课用约 3 分钟讲评。
