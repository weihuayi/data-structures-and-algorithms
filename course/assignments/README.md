# Assignments | 课程作业共同规范

每次课的正式 A/B 作业由对应 Deck 的课后作业页定义，`slides.py` 是具体任务主源，`index.html` 为受控派生物。本目录仅维护[共同作业规范](homework-guide.md)，**不另建重复的题号与任务正文**。

课件中自学、挑战、选做等内容不自动成为必做；一次飞书集中收取可以涉及多次课或多个 Deck，截止时间及实际收集入口由当届教师/助教通知。Offering 只记录有真实依据的实施和公开安排，不替代课程作业题目。已发布的要求若调整须明确告知，不能靠改 Git 历史追溯追加。

学生通过飞书提交个人作业，公开 `submissions/` 仅用于适合公开的独立贡献任务。助教可用 AI 辅助预检完整性、可运行性和共性错误，但真实性、理解及学习效果仍需人的专业判断。
