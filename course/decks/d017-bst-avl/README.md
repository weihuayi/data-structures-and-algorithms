## 一、教学中心与关键判断

**主问题**：数据不断变化时，怎样既保持有序查找的正确性，又避免搜索路径越来越长？

**核心认知跨越**：从 D016 的“利用已有有序信息减少比较”，转向“主动维护数据结构的顺序与平衡性质，使动态操作的正确性和计算代价在明确条件下得到保障”。

- **BST（Binary Search Tree，二叉搜索树/二叉排序树）**：以递归的关键字顺序性质支持查找、插入和删除；顺序正确不等于树高有保证。
- **AVL 树**：在 BST 之上要求每个结点的左右子树高度差绝对值不超过 1；树高有对数上界。动态更新时，以局部旋转在保持 BST 顺序性质的前提下修复失衡。
- **两类性质职责不同**：BST 顺序性质支持操作的合法性和查找排除依据；AVL 高度约束支持最坏情况下搜索路径长度的控制。
- **维护代价不可省略**：AVL 的整体时间结论依赖有效的高度/平衡信息维护、沿路径更新与适当旋转；图示、代码测试通过和教学效果分别需要不同证据。

以上为本讲设计的专业判断基础，不要求将所有证明细节逐一搬入课堂。

### 对象和数学约定

- 主例为**互异、可全序比较的关键字**；按关键字查找。重复键策略、关键字原地修改、并发更新、失败查询概率等均不在主线中默认解决。
- **树高按层数计**，与 D008/D009 一致：`h(空树)=0`，单结点树高度 1，`h(T)=1+max(h(L),h(R))`。教师 R1 推导曾使用按边数计（空树 -1）的等价约定；课件只采用前述按层数口径，使用另一来源时须明确换算。
- **BST 顺序性质**：每个结点左子树的所有关键字均小于该结点关键字，右子树所有关键字均大于它；左右子树递归满足同一性质，而非只比较直接孩子。
- **AVL 平衡因子**：`BF(v)=h(L(v))-h(R(v))`；树的**每一个**结点都要满足 `|BF(v)|<=1`。
- **复杂度**：普通 BST 查找、单次插入/删除按搜索高度为 `O(h)`，最坏 `O(n)`；AVL 树高 `O(log n)`，在适当维护高度及指针关系的实现下查找、插入和删除最坏 `O(log n)`。不把平均代价、最坏代价或实际运行时间混为一谈。
- 若为教师证明 AVL 高度上界：在本层数约定下，最少结点数 `N(0)=0, N(1)=1, N(h)=1+N(h-1)+N(h-2)`（`h>=2`）；高度为 `h` 的最小 AVL，两棵子树高可为 `(h-1,h-2)` 或对称互换；`(h-1,h-1)` 合法但不是最小结点构造。课堂可只给出“结点数随高度至少指数增长”的解释，完整证明供教师掌握/延伸。
- **旋转**的一般性正确性与平衡恢复条件分开：局部左/右旋始终保持有关子树的中序关键字顺序；仅在匹配的高度与失衡类型条件下才保证修复平衡。插入与删除有共同旋转形式，但删除可能需要向上重复修复。

## 五、主例状态、独立任务与正确结果

七个互异关键字`K={16,20,27,30,36,44,55}`；高度按层数计（空树0、单结点1）。

- **T0原树**：从空树按`30,20,44,16,27,36,55`插入。根30，左20（左16、右27），右44（左36、右55），高3。
- **T1插入后**：从T0把25插在27左空链接。必须同时满足`25<30`、`25>20`、`25<27`；完整树与独立提问要同屏。
- **T2删除后**：从T1删除根关键字30，选前驱27；课堂采用**复制前驱关键字及关联业务数据（不复制左右链接或高度缓存），再删原前驱结点**的语义。由于原27有左孩子25，须把20右链接接向25；最终根关键字27，左20（16、25），右44（36、55）。结点整体迁移属于另一种实现，不能混讲指针重接。
- **S3重新构造**：不继承T2。从空树分别按`30,20,44,16,27,36,55`和`16,20,27,30,36,44,55`插入，得高3与高7的普通BST，查找55的访问次数3和7；成功等概率ASL为17/7和4，不能无条件声称平均代价。
- **AVL示范**：LL序列30、20、16导致对30右旋；LR序列30、16、20说明只右旋后新根16的BF=-2，必须先左旋16、后右旋30。两个性质（BST顺序和AVL高度）分别核验。
- **候选新版独立题**：初始AVL根30，左20（左10、右25），右40；插入27导致LR，最低失衡祖先30；先左旋20再右旋30，最后根25，左20（左10），右30（左27、右40）。**现行32页课件独立题仍是插入5，尚未发布此题。**

T0/T1/T2是为设计和跨页一致性设定的状态标识，学生侧应以“原树／插入后／删除后／重新构造”说明，不要求背记版本名。
