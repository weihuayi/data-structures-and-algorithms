# D011｜图：一般关系结构

## 设计卡：本质关系

图把“哪些对象直接相关”作为计算对象的一部分。树的单一归属与无环条件不再是默认前提；边可以有方向、权值，图也可以不连通。建模先明确顶点、边的含义和任务需要的信息，再以查询邻接、枚举邻居等操作为依据选择表示。

邻接矩阵为所有顶点对留位置，邻接表只为实际关系建立条目。二者表示同一个逻辑对象，但直接查询和枚举邻居的机制不同。重点是 PO、REP、ABS、JDG、TRN，而不是提前教完图上的算法。

设计依据为课程认知主线 v0.2、D001–D020 Matrix v0.1 的 D011 条目，以及 WhyOS 课程理解 Memo v0.3。学习证据仍需真实课堂收集，不能由构建或程序检查代替。

## 主要问题与案例

问题链：道路为什么不能强行当树 → 哪些对象和关系必须保存 → 有向与带权如何改变语义 → 邻接与可达有何不同 → 计数能检查什么 → 什么接口需要什么表示 → 删除关系如何保持一致 → 陌生情境怎样建模并选择。

### 无向道路主例

顶点 A、B、C、D、E，边 AB、AC、BC、CD。E 为孤立点。

- 度数 2、2、3、1、0，总和 8=2m。
- A 到 D 没有直接边，但有路径 A—C—D。
- A—B—C—A 是环。分量为 {A,B,C,D}、{E}。
- n=5、m=4，说明 m=n−1 并不足以判断为树。
- C 的邻居为 A、B、D；矩阵枚举扫描 5 格，链表枚举访问 3 项。
- 删除 BC 后 m=3，度数为 2、1、2、1、0，总和 6；E 仍孤立。

### 有向时间网

独立约定弧 AB:4、AC:0、BC:2、CD:3、DB:1，单位为分钟。零权是模型中的即时转接，不解释为无边。

- 出度 2、1、1、1、0；入度 0、2、2、1、0；总和各为 5。
- A 能到 B，但 B 不能回到 A。强连通分量为 {A}、{B,C,D}、{E}。
- A→C→D 长度为 2、总权值为 3；A→B→C→D 长度为 3、总权值为 9。
- 图上画得近不意味着权小；图本身允许表示多种权值，当前演示只接受非负整数。

### 独立建模与表示判断：课程先修

P 是 Q、R 的先修，Q、R 是 S 的先修。约定先修→后续，边 PQ、PR、QS、RS。主要操作为枚举直接后续课程。加 SP 后出现有向环，图仍能保存这些关系，但可执行的先修安排不再成立。

## 实现边界

- 固定 1–8 个顶点，以整数编号访问。只接受无自环、无重复边的简单图及非负整数权；允许零权与空边集。无向输入的反向重复也被拒绝，有向的互反两条弧可以并存。
- 查询区分 FOUND、ABSENT、INVALID_VERTEX；权值输出只在 FOUND 时有效。图接口只回答邻接，不回答任意路径可达性。
- 邻接表由合法矩阵转换，按编号递增列邻居；该转换要扫描 n² 个位置。邻居枚举的列表开销是 O(1+d)，不能用构造成本代替查询成本。
- 无向边只计一次，矩阵和表均维护两份邻接记录。删除不存在的边不改变边数；删除有向边不会自动删除反向边。
- 链表结点动态分配；失败会释放已建条目。输出 Lists 必须尚未持有分配资源，使用完调用 `lists_destroy`。构建好的 Lists 不应按值复制后分别释放。
- MAX_V 是演示容量，矩阵和表头实际固定分配；正文中的 Θ(n²)、Θ(n+m) 比较指随规模分配的表示模型。运行时两种表示同时存在用于核对，不是节省内存的部署方式。
- 内置断言覆盖孤立顶点、单顶点无边、无向/有向、零权、自环、重复边、非法编号、负权、重复删除和反向弧保留。编译时不要定义 `NDEBUG` 后声称断言已执行。
