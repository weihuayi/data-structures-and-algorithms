主案例

先看连接，再决定保存什么

A ─── B        E
 \   /
   C ─── D

实际道路清单：AB、AC、BC、CD，均可双向通行。
E 是暂时没有道路接入的站点。

示意图只表示连接，不按实际距离绘制。道路清单是本例的关系约定。

教学注记

让学生用道路清单逐条核对图中的端点。图的位置布局可以改变，边集不变就表示同一组连接关系。

教学注记

第 3 页使用 E 同时作站点名和本页边集符号，讲授时读作“站点 E”与“边集合”。公式中 G=(V,E) 沿教材标准记法，程序用 edges 避免混淆。现实道路可有平行路线，本讲简单图模型只保留每对地点最多一条关系。

教材定义

图怎样定义？方向改变了什么？

教材定义（概述）
图 G=(V,E) 由顶点的非空有限集合 V 和边的有限集合 E 构成。无向图的边表示无序顶点对；有向图的弧表示有序顶点对。

无向边 {A,B}={B,A}，只计一条边。
有向弧 ⟨A,B⟩ 与 ⟨B,A⟩ 是两个可能不同的关系。

本讲采用简单图：无自环、无重边；允许边集为空。

方向与属性

同一批站点，任务改变后边会怎样？

单向时间网（单位：分钟）
A→B:4    A→C:0    B→C:2
C→D:3    D→B:1    E 孤立

A→C 的 0 表示模型中的即时转接，边仍然存在。
本页是另一组关系约定，不能从前面的无向图自动推得。

带权图也称网。本讲演示采用非负整数权，后续算法另说明各自的条件。

计数检查

度数怎样核对边有没有记错？

图顶点 A、B、C、D、E总和
无向主例的度2、2、3、1、08=2×4
有向时间网的出度2、1、1、1、05
有向时间网的入度0、2、2、1、05

无向边为两个端点各贡献 1；有向弧贡献一次出度、一次入度。

教学注记

回收 D008 的双重计数。自环口径此处不展开，因为模型已排除自环。孤立顶点的度是 0，但它仍是顶点集合的一员。

路径与环

一条路径的“长度”到底数什么？

无向主例中，A—C—D 是路径，经过 2 条边。
A—B—C—D 经过 3 条边；A—B—C—A 构成环。

在时间网中，A→C→D 的总时间为 0+3=3。
A→B→C→D 的总时间为 4+2+3=9。

本讲把经过的边数称为路径长度，把边权之和另称总权值。简单路径不重复顶点。

教学注记

环的起止顶点相同，简单环除起止外不重复顶点。图上画得短不表示权值小。这里只计算给定路径，不讲最短路径算法。

连通性

没有直接相连，就一定到不了吗？

A 与 D 没有直接边，但可以经过 C 到达。
E 与其他顶点之间没有路径。

教材定义（概述）
无向图中，若任意两个顶点之间都有路径，称为连通图。极大的连通子图称为连通分量。

本例的连通分量：{A,B,C,D} 与 {E}。

教学注记

“极大”表示不能再加入本图其他顶点而仍保持连通，不是结点数必须全图最大。孤立顶点单独构成一个分量。不要把非邻接与不可达混同。

有向可达性

有方向时，“能到”还能倒过来说吗？

在第 6 页的时间网中，A 能到 B，B 却不能回到 A。

教材定义（概述）
有向图中，若任意两个顶点之间都存在双向的有向路径，称为强连通图。极大的强连通子图称为强连通分量。

本例强连通分量：{A}、{B,C,D}、{E}。
忽略方向后连在一起，不保证沿箭头互相到达。

教学注记

B→C→D→B 构成有向环。单顶点到自身允许长度 0 的路径，所以 A、E 各构成一个强连通分量。本页只辨认小图，不引入强连通分量算法。

回收树与森林

树与一般图，相差哪些条件？

对象（无向简单图语境）连接条件边数关系
树连通且无环n 个顶点有 n−1 条边
森林无环，可有多个分量c 个分量时 m=n−c
一般图可能有环，也可能不连通只靠 m=n−1 不能判定是树

主例 n=5、m=4，却有三角形 A—B—C—A 和孤立点 E。

教学注记

无向图的“根”可以为任务另选；图本身未必指定根。主例正好提供 n−1 条边但不是树的反例。

性质与条件

最多能连多少条边？

模型：n 个顶点，无自环重边最多边数理由
无向完全图n(n−1)/2每个不同顶点对只计一次
有向完全图n(n−1)每个有序的不同顶点对可有一条弧

非连通无向图还能有很多边：
9 个顶点中，8 个组成完全图、另 1 个孤立，就有 28 条边。

教学注记

对应正式作业选 (5) 的推理入口：非连通 n 顶点简单无向图的最大边数为 (n−1)(n−2)/2，集中到 n−1 个顶点的完全图，再留一个孤立点达到上界。n=8 时最多21，n=9 时可28。稠密/稀疏是相对 n² 的描述，不机械设一个通用分界值。

1 表示有边，0 表示无边；此表只表示无权简单图的邻接关系。

表示不变量

矩阵中哪些性质来自图，而非排版？

  • 无向图满足 M[u][v]=M[v][u]。
  • 无自环，所以对角线全为 0。
  • 无向主例共有 8 个 1，对应 4 条边。

教学注记

先让学生在第 14 页独立数一行、一列、所有非零项。不能把对称性推广到有向图，也不能把二值邻接矩阵的“非零个数”规则不加区分地用于允许零权边的权值矩阵。

信息编码

权值为 0 时，怎么区分“有边”和“无边”？

bool present[MAX_V][MAX_V];
int  weight[MAX_V][MAX_V];

present[A][C] = true;  weight[A][C] = 0;
present[A][E] = false; // weight[A][E] 不参与解释

边是否存在与边的权值分别保存。
“A→C 权为 0”和“A→E 无边”必须得到不同答案。

教学注记

教材常以 ∞ 表示带权矩阵无边；C 代码若采用哨兵值，须约定合法权值范围并处理后续加法。本课用存在标记避免混淆，不进行距离矩阵初始化。对角无自环不妨碍顶点到自身的长度0路径。

邻接表

D: C

每个顶点一个表头，边结点记录邻居和可选权值。
无向边在两个端点的表里各出现一次。

这是无向主例的一种邻接表。链表次序是表示约定，不是新增加的道路关系。

有向图的邻接表，该列入边还是出边？

出边邻接表的表长是出度；入度需要扫描各表或额外维护计数/逆表。这里指出表示选择的依据，完整四种表示练习按既有清单留到 D012。

能力与代价

同一个接口，两种表示要读多少东西？

操作：已知有效顶点编号邻接矩阵链式出边邻接表
判断 u→v 是否存在O(1)O(1+d⁺(u))，最坏扫描整表
列 u 的出邻居Θ(n)，扫描一行Θ(1+d⁺(u))，只访问已有条目
空间（可随规模分配）Θ(n²)Θ(n+m)；无向边存两份

n 为顶点数，m 为边或弧数；无向图把 d⁺ 换成度。空表判断有常数开销。

教学注记

排除通过名字寻找编号的代价。本演示为矩阵与表头预留 MAX_V 固定容量，实际分配不能直接冒充渐近表达式。大 O 比较不直接等于实际运行时间，缓存和分配也影响常数。

修改与约束

删除一条无向边，为什么要改两处？

关闭主例中的 BC 道路：

表示需要修改仍应保持
邻接矩阵M[B][C]、M[C][B] 同时清除对称性
邻接表从 B 表删 C，从 C 表删 B每条无向边存两份
