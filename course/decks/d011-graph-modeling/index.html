第一节 · 从现实关系到图模型

什么是图？

教材定义（概述）
图（Graph）\(G=(V,E)\) 由顶点的非空有限集合 V 和边的有限集合 E 构成。无向图的边表示无序顶点对；有向图的弧表示有序顶点对。

无向边 {A,B}={B,A}，只计一条边。
有向弧 ⟨A,B⟩ 与 ⟨B,A⟩ 是两个可能不同的关系。

本讲采用简单图：无自环、无重边；允许边集为空。

第一节 · 从现实关系到图模型

方向与权值改变了什么？

有向图（Directed Graph）：箭头保存允许通行的方向，反向弧不自动存在。

权值保存通行时间；带权图也称网。

A→C 的 0 是即时转接，仍有边。

这是独立约定的五条弧，不能由道路图直接推出。

路径、路径长度与环怎样定义？

教材定义（概述）
路径是相邻顶点连接成的序列；路径长度为经过的边或弧数。首尾相同的路径称回路或环。

A—C—D：长度 2。A—B—C—A：环。

简单路径不重复顶点；简单环除首尾外不重复顶点。

方向改变后，可达性会怎样变化？

A 能到 B，B 却不能回到 A。

A→C→D：2 条弧，总权值 3。
A→B→C→D：3 条弧，总权值 9。

边数与总权值是不同量。

怎样只保存实际存在的邻居？

A: [B] → [C] → NULL
B: [A] → [C]* → NULL
C: [A] → [B]* → [D] → NULL
D: [C] → NULL
E: NULL

邻接表（Adjacency List）：* 是 BC 的两份邻接项。→ 仅是 next 链接，不是道路；E 仍占一个表头。固定编号与编码后矩阵唯一，邻接表记录顺序可以改变。

出邻接（邻居,权值）
A: (B,4) → (C,0) → NULL
B: (C,2) → NULL

第四节 · 操作、代价与表示选择

枚举一个顶点的邻居，工作量为何不同？

矩阵 C 行： [1][1][0][1][0]
检查位置：   A  B  C  D  E
邻接表 C： [A] → [B] → [D]
访问条目：  ①     ②     ③

矩阵扫描 5 格：\(\Theta(n)\)；邻接表访问 3 项：\(\Theta(1+d(C))\)。空表仍有常数开销。

第四节 · 操作、代价与表示选择

图的规模怎样影响空间与表示选择？

无自环、无重边：无向图最多 \(n(n-1)/2\) 条边；有向图最多 \(n(n-1)\) 条弧。

按规模分配普通矩阵普通邻接表
空间\(\Theta(n^2)\)\(\Theta(n+m)\)；无向有 2m 项
n=10000，m=30000一亿个位置一万表头 + 三万弧项 / 六万无向项

少量边、主要枚举时通常倾向表；大量指定对查询时还要权衡矩阵内存、查询频率与常数。不是仅按稀疏/稠密决定。

教学注记

顶点对计数：无向每对计一次，有向每对有两个方向。若每矩阵位置4字节，一亿位置约400 MB，不含顶点及辅助信息；演示 MAX_V=8 固定容量不做此规模实测。矩阵转表扫描 n² 格，与建好表示上的查询是不同成本。非连通图上界 (n−1)(n−2)/2；8 顶点最多21边，9 顶点可有28边，服务选择(5)。

M[B][C]、M[C][B]：1 → 0
B 表：[A,C] → [A]
C 表：[A,B,D] → [A,D]

删除一条边，同步维护两份记录。边数 4→3；度数 2、1、2、1、0，总和 6。

链表同时释放两个边结点。不存在的边不再次减数；非法顶点单独报告。矩阵保持对称，其他关系不变。E 仍孤立，全图仍不是树。
