第一节 · 从现实关系到图模型

什么是图？

教材定义（概述）
图（Graph）\(G=(V,E)\) 由顶点的非空有限集合 V 和边的有限集合 E 构成。无向图的边表示无序顶点对；有向图的弧表示有序顶点对。

无向边 {A,B}={B,A}，只计一条边。
有向弧 ⟨A,B⟩ 与 ⟨B,A⟩ 是两个可能不同的关系。

本讲采用简单图：无自环、无重边；允许边集为空。

第一节 · 从现实关系到图模型

方向与权值改变了什么？

有向图（Directed Graph）：箭头保存允许通行的方向，反向弧不自动存在。

权值保存通行时间；带权图也称网。

A→C 的 0 是即时转接，仍有边。

这是独立约定的五条弧，不能由道路图直接推出。

第二节 · 理解图中的关系

路径、路径长度与环怎样定义？

教材定义（概述）
路径是相邻顶点连接成的序列；路径长度为经过的边或弧数。首尾相同的路径称回路或环。

A—C—D：长度 2。A—B—C—A：环。

简单路径不重复顶点；简单环除首尾外不重复顶点。

第二节 · 理解图中的关系

方向改变后，可达性会怎样变化？

A 能到 B，B 却不能回到 A。

A→C→D：2 条弧，总权值 3。
A→B→C→D：3 条弧，总权值 9。

边数与总权值是不同量。

教学注记

强连通要求任意不同顶点间均有双向有向路径。本例强连通分量（Strongly Connected Component）为 {A}、{B,C,D}、{E}，不展开算法。对当前可见时间网逐弧计数：出度 2、1、1、1、0；入度 0、2、2、1、0，各和为5。用 m 表示弧数，则 \(\sum_v d^+(v)=\sum_v d^-(v)=m\)，每弧贡献一次出度和一次入度。

第二节 · 理解图中的关系

怎样通过度数检查图的关系？

\(n=|V(G)|\)：顶点数。
\(m=|E(G)|\)：边数；有向图按弧数计。

\(d(v)\) 是与顶点 v 关联的边数。

BC 为 B、C 各贡献 1；每条无向边均有两个端点。

\(2+2+3+1+0=8=2m\)
故 \(\sum_v d(v)=2m\)。

教学注记

当前简单无向图 n=5、m=4，E 的度为0。教材用 e 表示边数，本讲统一用 m；有向图的出度、入度及弧数在第12页时间网注记中对照。

第二节 · 理解图中的关系

有 n−1 条边就一定是树吗？

主例 \(n=5,m=4=n-1\)。
它有环及孤立顶点 E，不是树。

树是连通且无环的无向图。

仅对无向森林：\(m=n-c\)，其中 c 是连通分量个数。该公式不能直接套用于左图的含环一般图。

第三节 · 将图转换为计算表示

怎样只保存实际存在的邻居？

head[0](A): 1(B) → 2(C) → NULL
head[1](B): 0(A) → 2(C)* → NULL
head[2](C): 0(A) → 1(B)* → 3(D) → NULL
head[3](D): 2(C) → NULL

邻接表（Adjacency List）：head[1] 对应 B；整数为编号，字母为辅助名。

第三节 · 将图转换为计算表示

有向图的邻接表如何保存方向？

出邻接：(to, weight)
head[0](A): (1,4) → (2,0) → NULL
head[1](B): (2,2) → NULL
head[2](C): (3,3) → NULL
head[3](D): (1,1) → NULL
head[4](E): NULL

每条弧仅记在弧尾的出表；逆邻接表按弧头记入邻居，例如编号1(B)的入邻居是0(A)、3(D)。→ 是存储链接。

教学注记

孤立点 E 仍有 head[4]=NULL。固定编号和编码约定后矩阵唯一；邻接表记录次序可变，不改变逻辑邻接关系。

第四节 · 操作、代价与表示选择

图的规模怎样影响空间与表示选择？

无自环、无重边：无向图最多 \(n(n-1)/2\) 条边；有向图最多 \(n(n-1)\) 条弧。

按规模分配普通矩阵普通邻接表
空间\(\Theta(n^2)\)\(\Theta(n+m)\)；无向有 2m 项
n=10000，m=30000一亿个位置一万表头 + 三万弧项 / 六万无向项

少量边、主要枚举时通常倾向表；大量指定对查询时还要权衡矩阵内存、查询频率与常数。不是仅按稀疏/稠密决定。

教学注记

顶点对计数：无向每对计一次，有向每对有两个方向。若每矩阵位置4字节，一亿位置约400 MB，不含顶点及辅助信息；演示 MAX_V=8 固定容量不做此规模实测。矩阵转表扫描 n² 格，与建好表示上的查询是不同成本。非连通图上界 (n−1)(n−2)/2；8 顶点最多21边，9 顶点可有28边，服务选择(5)。
