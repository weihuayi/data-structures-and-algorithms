条件

怎样判断这些关系组成一棵树？

① 唯一根：A 没有父结点。

② 其余结点各有一个父结点。

③ 沿父关系最终都能到达 A。

若再让 G 成为 B 的父结点，哪条条件被破坏？

教学注记

B 已有父结点 A，再加 G 会破坏唯一父结点条件。仅有唯一根、其余单亲仍不够：A 独立为根而 B、C 互为父结点就是反例。

教材定义

树为什么能递归定义？

教材定义（概述）
树是有限个结点的集合，可以为空；非空时有唯一根，其余结点分成若干互不相交的非空集合，每个集合又是一棵树，称为根的子树。

去掉 A，两部分仍遵循同样规则。

教学注记

对应教材 5.1，定义为概述。子树互不相交排除共享结点。一般树不限定两个孩子，本例左右排版不代表左、右位置语义。回收 D006：递归先是对象的定义。

关系术语

谁是谁的父结点、孩子和兄弟？

A 是根，没有父结点。

D 的父结点是 B。
B 的孩子是 D、E。
D 与 E 有同一个父结点，是兄弟。

父结点（教材术语：双亲，parent）。
“双亲”在这里指一个父结点，不是两个。

数量与位置

度和层次分别数什么？

度数孩子：B 的度为 2；
树的度是各结点度的最大值，为 2。

叶子度为 0：D、E、F、G。
分支结点度大于 0：A、B、C。

层次数位置：根在第 0 层，D 在第 2 层；结点深度等于层编号。

本讲高度 height 按层数计：本例共 3 层，最大层编号为 2；空树高度为 0。A 到 D 的路径长为 2。

表示与选择

表示怎样改变操作的代价？

操作（已知结点标识）双亲数组孩子表
找父结点\(O(1)\)：读一个元素\(O(n)\)：最坏扫描各表
列直接孩子\(O(n)\)：扫描双亲数组\(O(k)\)：读 \(k\) 个孩子
沿归属路径回到根\(O(h)\)：逐层上行需反查父结点或增存信息

孩子表无父指针，表头可直接定位；\(n\) 为结点数，\(k\) 为孩子数，\(h\) 为高度。按名字定位结点的代价另算。

教学注记

回收 D003/D004：比较的是同一抽象关系上的具体操作。孩子表全扫描的总条目为 \(n-1\)，不是每个表都有 \(n\) 项。额外存双亲能加速上行，但修改时要保持两套信息一致。

不变量回收

改一个父结点，为什么还可能出错？

若只改数组，把模型 B 的父结点设为网格 D：

parent[1] = 3;

但 D 原本就在 B 的子树内。

parent[3] = 1
parent[1] = 3
沿 parent 反复走回原处，无法到根。

教学注记

真实文件不能容纳子目录；这里暂只检查抽象父关系，说明下标合法仍可能成环。图保留修改前结构，右侧两项明确展示修改后成环。迁移前须排除新父结点在自己的子树内；同时保存孩子表时也要同步更新。下标合法不等于关系合法。

第二案例

算式里，两个孩子能交换吗？

减号的左操作数是 a，
右操作数是 b。

交换后，\(a-b\) 变成 \(b-a\)。

除了父子关系，还必须保存左、右位置。

教材定义

二叉树只是“度不超过 2 的树”吗？

教材定义（概述）
二叉树可以为空；非空时由根和互不相交的左子树、右子树组成，两棵子树本身也是二叉树。

这是两种不同的二叉树。缺失的左、右位置也是结构信息。

C 表示

左右位置怎样进入 C 结构？

typedef struct Node {
    char data;
    struct Node *left;
    struct Node *right;
} Node;

空树用 NULL；左孩子缺失用 left == NULL。
叶子要求左右指针都为空。

教学注记

二叉链表是一种表示，不是二叉树的定义。约定每个非根结点只被一个父结点引用、无环且全部可从根到达。相同 data 不表示同一个结点。

程序

怎样在内存中接出这棵树？

Node a = {'a', NULL, NULL};
Node b = {'b', NULL, NULL};
Node minus = {'-', &a, &b};
Node c = {'c', NULL, NULL};
Node d = {'d', NULL, NULL};
Node plus = {'+', &c, &d};
Node root = {'*', &minus, &plus};

这些局部对象在当前函数返回前有效。指针记录关系，不要求结点地址相邻。

教学注记

课堂代码在 main 内使用这些对象，不返回悬空指针，不涉及动态申请与释放。确认学生能指出 root.left->right 对应 b。

形态与条件

“满”和“完全”，从图上怎样判断？

满：高度 \(h\) 时有 \(2^h-1\) 个结点。
完全：恰好占据满二叉树按层从左到右编号的前 \(n\) 个位置。

教学注记

所有满二叉树都是完全二叉树。右图每个分支都有两个孩子，但仍不满；本课“满”采用中文教材口径，不混用英文 full 的另一种常见定义。

性质的理由

每一层最多多少结点？

根在第 0 层；每个结点最多有两个孩子。

第 \(i\) 层最多 \(2^i\) 个结点（\(i\geq0\)）。

共 \(h\) 层，编号 \(0\) 至 \(h-1\)，最多：

\[\sum_{j=0}^{h-1}2^j=2^h-1\]

非空二叉树：\(\lceil\log_2(n+1)\rceil\le h\le n\)。
完全二叉树：\(h=\lfloor\log_2 n\rfloor+1\)。

教学注记

本讲 h 按层数计，非空树的最大层编号为 h−1。遇到教材从 1 编层时，先换算编号，不混用公式。上下界分别由尽量填满和单链达到。\(n=1025\) 时一般二叉树高度范围为 11 至 1025，完全二叉树高度为 11。式子描述形态，不证明一般二叉树查找为 \(O(\log n)\)。

性质的理由

叶子数为什么比双孩子结点多 1？

非空二叉树中，\(n_0\)、\(n_1\)、\(n_2\) 分别计数度为 0、1、2 的结点。

\[\begin{aligned}n &= n_0+n_1+n_2\\n-1 &= n_1+2n_2\\n_0 &= n_2+1\end{aligned}\]

为什么边数是 \(n-1\)？每个非根结点恰好贡献一条入边。

教学注记

空树不适用 \(n_0=n_2+1\)。一般非空树可推广为叶子数 \(n_0=1+\sum_{k\ge1}(k-1)n_k\)。重点让学生说明同一个量为何能用两种方式数，不把恒等式当成树合法性的充分条件。

顺序表示

用编号代替指针，行不行？

从 0 起按满二叉树的位置编号，缺失位置仍保留。

位置 \(i\) 的左孩子：\(2i+1\)
右孩子：\(2i+2\)
\(i>0\) 时父位置：\(\lfloor(i-1)/2\rfloor\)

完全二叉树恰好占据 \(0,\ldots,n-1\)。

这里为该形状指定左右位置。根的位置为 0。双亲数组下标标识结点，这里的位置还编码左右结构；访问前须检查位置是否存在。

表示的边界

只有右孩子时，数组会怎样？

位置0123–567–1314
结点A空B空C空D

最大位置为 14，要分配 15 个槽位，
有效结点只有 4 个。

若紧凑装入 \(0,\ldots,3\)，
\(2i+1\)、\(2i+2\) 就不再表示原来的孩子。

高度 \(h\) 的右单链末位置为 \(2^h-2\)。空位必须显式标记，不能用某个合法数据值冒充。

判断与选择

什么时候选数组，什么时候选链式？

需求 / 形态位置数组二叉链表
完全二叉树 \(n\) 个连续有效位置；下标定位可表示，但需两个孩子指针
稀疏或偏斜二叉树可能浪费大量空位置每个结点固定两个孩子指针
已知结点找父结点可用下标公式没有父指针时需另找

空间、定位能力和修改需求共同决定选择。

教学注记

不把“链式插删 \(O(1)\)”无条件搬过来，重接链接前可能要定位、检查约束。本课不讨论 BST 的有序性或堆序，它们是后续追加的性质。
