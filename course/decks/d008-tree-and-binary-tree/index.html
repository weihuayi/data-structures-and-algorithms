问题与对象

只列出名字，丢掉了什么？

D007 留下的问题：关系如果不是“一个接一个”，而是“一个下面有多个”？

实验资料、模型、结果、网格、参数、图像、报告

“网格属于谁？”“结果下面有什么？”
这些问题仅靠名字序列能回答吗？

教学注记

让学生先补画关系。列表可以编码树，但必须增加父子等关系信息。不要把“线性存储”误说成“不能表示层次关系”。

主案例

我们要保存哪些层次信息？

A 实验资料
├── B 模型
│   ├── D 网格
│   └── E 参数
└── C 结果
    ├── F 图像
    └── G 报告

操作：找父目录、列直接孩子、确定一条归属路径。

A–G 是唯一标识，名字是数据。本例只研究单一归属，不含链接。

条件

怎样判断这些关系组成一棵树？

  • 有一个根：A 没有父结点。
  • 其余每个结点恰有一个父结点。
  • 每个结点沿父关系最终都能到达 A。

增加 G→B，让 B 同时属于 A 和 G，还符合条件吗？

教学注记

不符合单亲约束。另一个反例：A 单独为根，B、C 互为父结点。仅有“一个根、其余单亲”还不够，必须排除环并保证归根可达。文件系统链接、多人合作关系都可能超出本例模型。

教材定义

树为什么能递归定义？

教材定义（概述）
树是 n（n≥0）个结点的有限集。n=0 时为空树；非空时有唯一的根，其余结点分为若干互不相交的非空集合，每个集合又是一棵树，称为根的子树。

去掉 A：以 B、C 为根的两部分，各自仍有同样的组织规则。

对应教材 5.1。回收 D006：递归先出现在对象定义中，之后才进入程序。

教学注记

定义按本课程教材口径概述，不作为逐字引文。子树互不相交排除了共享结点。树不一定有两个孩子，B、C 的左右排版也不自动赋予次序语义。

概念锚定

根、度、层次分别在说什么？

术语实验资料树中的对应
根 / 双亲 / 兄弟A / D 的双亲 B / D 与 E
结点的度 / 树的度孩子数 / 所有结点度的最大值，本例为 2
叶子 / 分支结点度为 0：D、E、F、G / A、B、C
层次 / 深度（高度）根在第 1 层 / 最大层次，本例为 3

路径长度数边：A 到 D 长度为 2。空树高度约定为 0。

计算表示

同一棵树，可以怎样存？

标识 iABCDEFG
parent[i]−1AABBCC
children[i]B,CD,EF,G空空空空

双亲数组记录“我属于谁”；孩子表记录“谁属于我”。
两种表示都能还原本例的父子关系。

数组里的相邻位置不代表树里的父子关系。这里先作表示比较，5.6 的完整体系留到 D010。

表示与选择

表示怎样改变操作的代价？

操作（已知结点标识）双亲数组孩子表
找父结点O(1)：读一个元素O(n)：最坏扫描各表
列直接孩子O(n)：扫描双亲数组O(k)：读 k 个孩子
沿归属路径回到根O(h)：逐层上行需反查父结点或增存信息

孩子表无父指针，表头可直接定位；n 为结点数，k 为孩子数，h 为高度。按名字定位结点的代价另算。

教学注记

回收 D003/D004：比较的是同一抽象关系上的具体操作。孩子表全扫描的总条目为 n−1，不是每个表都有 n 项。额外存双亲能加速上行，但修改时要保持两套信息一致。

不变量回收

改一个父结点，为什么还可能出错？

把“模型 B”移到“网格 D”下面：只改 parent[B]=D。

修改前：D → B → A
修改后：D → B → D → …

赋值合法，关系却成了环。迁移子树前，必须排除“新父结点在自己的子树内”。

教学注记

本页只识别必须保持的条件，不编写通用移动算法。若还保存孩子表，旧父与新父的孩子记录也须更新。请学生区分 C 下标合法与表示的对象合法。

第二案例

算式里，两个孩子能交换吗？

把 (a − b) × (c + d) 的结合关系保存下来：

          ×
       /     \
      −       +
     / \     / \
    a   b   c   d

交换减号下面的 a、b，算式就变了。
这里不仅要保存父子，还要保存左、右位置。

教材定义

二叉树只是“度不超过 2 的树”吗？

教材定义（概述）
二叉树是结点的有限集合，可以为空；非空时由根和两棵互不相交的二叉树组成，分别称为左子树和右子树。
只有左孩子： A       只有右孩子： A
             /                      \
            B                        B

这是两种二叉树。缺失的位置也属于结构信息。

对应教材 5.1。一般树即使最多两个孩子，也未必定义了左、右位置。

C 表示

左右位置怎样进入 C 结构？

typedef struct Node {
    char data;
    struct Node *left;
    struct Node *right;
} Node;

空树用 NULL；左孩子缺失用 left == NULL。
叶子要求左右指针都为空。

教学注记

二叉链表是一种表示，不是二叉树的定义。约定每个非根结点只被一个父结点引用、无环且全部可从根到达。相同 data 不表示同一个结点。

程序

怎样在内存中接出这棵树？

Node a = {'a', NULL, NULL};
Node b = {'b', NULL, NULL};
Node minus = {'-', &a, &b};
Node c = {'c', NULL, NULL};
Node d = {'d', NULL, NULL};
Node plus = {'+', &c, &d};
Node root = {'*', &minus, &plus};

这些局部对象在当前函数返回前有效。指针记录关系，不要求结点地址相邻。

教学注记

课堂代码在 main 内使用这些对象，不返回悬空指针，不涉及动态申请与释放。确认学生能指出 root.left->right 对应 b。

形态与条件

同样是二叉树，“满”和“完全”差在哪里？

形态判定（高度为 h）例子
满二叉树每一层都达到最多结点数高度 3 时共有 7 个结点
完全二叉树与满二叉树按层从左到右编号的前 n 个位置一致最后一层从左连续占据
一般二叉树只要求左、右子树位置明确可只有右孩子

所有满二叉树都是完全二叉树。
“每个分支都有两个孩子”足以判满吗？

教学注记

不够。根有两个孩子，其中一个是叶子，另一个还有两个叶子：共 5 个结点，高度 3，不满也不完全（若右侧分支更深）。本课“满”采用中文教材口径，不能与英文 full 的另一常用口径混用。

性质的理由

第 i 层最多多少结点？

根在第 1 层：最多 1 个。每往下一层，每个结点最多提供两个孩子。

第 i 层最多：2^(i−1)
高度 h 最多：1 + 2 + … + 2^(h−1) = 2^h − 1

非空二叉树：⌈log₂(n+1)⌉ ≤ h ≤ n。
完全二叉树：h = ⌊log₂ n⌋ + 1。

教学注记

上下界分别由尽量填满和单链达到。n=1025 时一般二叉树高度范围为 11 至 1025，完全二叉树高度为 11。式子描述形态，不证明一般二叉树查找为 O(log n)。

性质的理由

叶子数为什么比双孩子结点多 1？

非空二叉树中，n₀、n₁、n₂ 分别计数度为 0、1、2 的结点。

数结点：n = n₀ + n₁ + n₂
数边：  n − 1 = n₁ + 2n₂
相减：  n₀ = n₂ + 1

为什么边数是 n−1？每个非根结点恰好贡献一条入边。

教学注记

空树不适用 n₀=n₂+1。一般非空树可推广为叶子数 n₀=1+Σ(k−1)nₖ（k≥1）。重点让学生说明同一个量为何能用两种方式数，不把恒等式当成树合法性的充分条件。

顺序表示

用编号代替指针，行不行？

从 1 起按满二叉树的位置编号，缺失位置仍保留：

            1:A
       2:B        3:C
     4:D  5:E   6:F  7:G

位置 i 的左孩子在 2i，右孩子在 2i+1。
i>1 时，父位置为 ⌊i/2⌋。

位置在范围内且确有结点，才能访问。完全二叉树恰好占据 1…n。

表示的边界

只有右孩子时，数组会怎样？

4 个结点的右单链：A → B → C → D
满树位置编号：    1   3   7   15
紧凑装进 1…4：    A   B   C   D

紧凑装入会改变 2i、2i+1 所解释的关系。
保留位置则要分配到 15，里面只有 4 个有效结点。

高度 h 的右单链末位置是 2ʰ−1。空位置要有显式标记，不能靠某个合法数据值猜测。

判断与选择

什么时候选数组，什么时候选链式？

需求 / 形态位置数组二叉链表
完全二叉树n 个连续有效位置；下标定位可表示，但需两个孩子指针
稀疏或偏斜二叉树可能浪费大量空位置每个结点固定两个孩子指针
已知结点找父结点可用下标公式没有父指针时需另找

空间、定位能力和修改需求共同决定选择。

教学注记

不把“链式插删 O(1)”无条件搬过来，重接链接前可能要定位、检查约束。本课不讨论 BST 的有序性或堆序，它们是后续追加的性质。
