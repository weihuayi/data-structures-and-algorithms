# D010｜树与森林的表示转换、哈夫曼编码

## 设计卡：本质关系

本讲处理两种不同的结构设计。孩子兄弟表示改变链接含义，使任意多个孩子可以通过两个链接域表达，同时保留原结点、父子归属和约定的次序。哈夫曼构造则在给定符号权值和前缀编码条件下改变树形及码长，使加权路径成本最小。

主要认知跨越为 REP、INF、ALG、COST、JDG：学生既要分清对象与表示，也要说明优化的目标量和适用条件。正确性部分以可逆关系检查、前缀性、交换与收缩的证明提纲支撑，不将某次运行成功替代普遍结论。

设计依据：课程认知主线 v0.2、D001–D020 Matrix v0.1 的 D010 条目及 WhyOS 课程理解 Memo v0.3。当前资产形成不等于已实施教学或学生已形成相应能力。

- **D009**：承接“多孩子如何表示”“频率不同如何改变树形”留问；以遍历序核对转换，编码译码沿树走。

## 主要问题与案例

问题链：多个孩子怎样进入两个链接 → 如何读回原关系 → 遍历如何对应 → 频率为何影响代价 → 变长编码怎样确定边界 → 怎样构造低 WPL 的树 → 为什么局部合并安全 → 编码收益有什么边界。

- **森林案例**：A 的孩子为 B、C、D，B 的孩子为 E、F；第二棵树 G 的孩子为 H。固定根次序 A、G，固定孩子次序如上。用递增标识扫描实现该次序。先序 ABEFCDGH，后序 EFBCDAHG。
- **森林独立小题**：根次序 P、T；P 的孩子依次 Q、R，Q 的孩子 S。非空链接 P.L=Q、P.R=T、Q.L=S、Q.R=R；R 的原父为 P，后根序与二叉中序均为 SQRPT。与 A–H 主例区分，不修改演示程序输入。
- **哈夫曼主例**：A、B、C、D 的次数为 8、4、2、2，合并权值 4、8、16，WPL=28，平均码长 1.75，等长内容为 32 bit。
- **对照**：4、4、4、4，WPL=32，与 2 bit 等长编码相同；交换主例 A、D 的码字会使 WPL 增至 40。
- **独立任务**：P、Q、R、S 权值 5、2、1、1，合并 2、4、9，WPL=15，平均码长 5/3，等长内容为 18 bit。
- **失败输入**：森林中的环、共享孩子、不可达结点；码字歧义、译码停在内部结点、未知符号及非法位字符。

## 实现与验证边界

- 森林示例最大 16 个结点，以编号递增确定根与兄弟次序。双亲合法性检查最坏 O(n²)，转换本身 O(n)，恢复 O(n)；恢复遇到环、共享、越界或不可达结点返回失败，失败的部分输出不得使用。打印遍历要求已经验证的表示。
- 哈夫曼示例支持 1–16 个符号（A 起连续单字节标识），权值为正整数。零权、空字母表、超容量以及权值或总成本溢出均返回失败。所有实际调用必须检查结果。
- 并列时按权值、再按结点编号选择，先选者为左子树。这是复现实验的约定，不是最优性的必要条件；等权输入可能有不同最优码表。
- 单符号树结构 WPL=0，但演示的传输约定给该符号码字 0，所以有效载荷按每次 1 bit 计。课堂 WPL/合并和对照使用至少两个符号，避免混用两个口径。
- 编码/译码仅接受已经成功构建的码表；输出容量不足、未知符号、非法位或末尾码字不完整均失败，清空有容量的输出。不提供文件格式、码表传输、纠错或完整压缩器。
- 两份程序含课堂断言，覆盖空森林、单树、多根、环、共享、坏链接，以及并列权、单符号、最大容量、整数溢出、编码译码失败路径。不要定义 `NDEBUG` 后声称课堂断言已经执行。
