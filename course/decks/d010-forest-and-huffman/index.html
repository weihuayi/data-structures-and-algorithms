教学注记

C 的原父为 A，不是 B；G 是另一个根。请学生沿 B→C→D 的右链还原 A 的孩子。若把 B.right=C 改成 B.left=C，会覆盖 E 并改变原关系，不能当作等价排版。

反向检查

怎样把二叉链接读回森林？

  1. 沿根的右链分出各棵树：A、G。
  2. 对每个结点，左链接给出第一个孩子。
  3. 从该孩子沿右链取出其余孩子，再逐层重复。
A 的孩子：B → C → D
B 的孩子：E → F        G 的孩子：H

验证：结点没丢，原来的父子归属与约定次序都恢复了。

教学注记

A.right=G 不表示 G 的父结点是 A。恢复时把整条兄弟链赋予同一个原树父结点。孩子链与根链必须无环、不共享结点。

回收遍历

原树的后根遍历，对应二叉树的什么顺序？

原森林（按根与孩子次序）二叉表示本例序列
先序：根，再各孩子子树先序 NLRA B E F C D G H
后序：各孩子子树，再根中序 LNRE F B C D A H G

左边编码“孩子”，右边编码“后续兄弟”。
原树的后根顺序，不能直接照搬成二叉后序。

教学注记

对应 5.6.3。森林先序为各树先根序串接；这里的森林后序按各树后根序串接，教材也常称森林中序。请学生以原关系定义为准核对。二叉中序先处理孩子链、再根、再后续兄弟，恰好符合这一顺序。

若 A=0，B=01，C=1
收到 01：可能是 B，也可能是 A C

教材定义（概述）

左边标 0，右边标 1

     A     ●
          / \
         B   ●
            / \

叶子不会是另一个叶子的祖先，因此码字互不为前缀。

教学注记

内部结点不放字符。这里先展示一棵可行编码树，不由“能译码”直接推断最优。译到叶子输出一个符号，再回到根继续。

目标函数

怎样把“短一些”写成可比较的目标？

教材定义（概述）
树的带权路径长度 WPL，是各叶子权值与根到该叶子路径长度的乘积之和。使给定叶子权值的 WPL 最小的二叉树称为哈夫曼树（最优二叉树）。
WPL = Σ wᵢ ℓᵢ
本例：8×1 + 4×2 + 2×3 + 2×3 = 28
平均码长：28 / 16 = 1.75 bit/符号

ℓᵢ 数边，根深度为 0；不同于 D008 从 1 开始计的层次。内部权值不直接计入这项求和。

比较与判断

同样四个符号，树形改变了多少代价？

方案A、B、C、D 的码长加权总位数
等长编码2、2、2、232
第 12 页的树1、2、3、328
把 A 与 D 的位置交换3、2、3、140

树形和符号位置共同影响代价。
若权值大却放得深，频繁操作就会反复付出长路径的成本。

教学注记

交换变化量为 (8−2)×(3−1)=12，28+12=40。树高低不是唯一优化目标；本例较高的树反而比等长树的 WPL 更低。

哈夫曼算法

怎样一步步构造低代价的树？

  1. 每个符号作为一棵单结点树，权值取出现次数。
  2. 选择根权值最小的两棵树，合成一个新根，权值为两者之和。
  3. 把新树放回待选集合，重复到只剩一棵。

每轮少一棵树。n 个符号需要 n−1 次合并。

教学注记

本讲取正权值、n≥2 的二元前缀编码。并列最小可以任选；为使代码与手算一致，演示按权值、再按结点编号排序，先选者放左边。算法依据不是“试起来不错”，下一段给出交换与收缩理由。

示例与补全

合成项放回后，下一轮选谁？

完整主例 8、4、2、2：合并 4 → 8 → 16，对照第 12 页。

补全例：A6、B3、C2、D1
第 1 轮：D1 + C2 = 新树3
待选：B3、新树3、A6
第 2 轮：____ + ____ = ____
第 3 轮：____ + ____ = ____

为什么不能只给最初的叶子排序一次？

教学注记

补全为 3+3=6、6+6=12，WPL=3+6+12=21。合成项仍代表待编码的一组符号，必须重新参与最小选择。先收补全，再展开答案；第 24 页另一组权值才作为独立构造证据。

代价核对

为什么合并权值之和恰好等于 WPL？

第 1 次合并：C、D 各多走 1 条边，代价 +4
第 2 次合并：B、C、D 各多走 1 条边，代价 +8
第 3 次合并：所有符号各多走 1 条边，代价 +16
总增量：4 + 8 + 16 = 28

每片叶子的权值，被累计的次数恰好等于它的深度。

教学注记

这一恒等式适用于逐次合并得到的每个内部结点恰有两个孩子的二叉树，不仅仅用于哈夫曼选择。代码用“叶子权值×码长”和“合并权值之和”两条路径交叉核对，但两者相等本身并不证明最优。

成立理由

为什么先合并最小两项是安全的？

  • 可以选取一棵最优树，使两个最小权值处在最深的一对兄弟叶子上。
  • 把这对兄弟收缩成权值之和，得到更小的同类问题。
  • 较小问题的最优树展开这对叶子，就给出原问题的最优树。

安全选择加上规模缩小，让局部选择可以持续进行。

教学注记

理由展开：正权下可去掉只有一个孩子的内部结点而降低 WPL，因此只需考虑每个内部结点有两个孩子的树。取最深兄弟叶子，把最小两权交换到那里不会增加代价，因为把小权移深、大权移浅的变化量≤0。收缩后若还能改进，展开即改进原树，矛盾。展开多付的固定量为两权之和。这是证明提纲，不以一个例子代替普遍理由。

计算表示

合成结点怎样存进 C 数组？

typedef struct {
    unsigned long long weight;
    int parent, left, right;
} HNode;
// 0 .. n-1 为叶子，n .. 2*n-2 为合成结点
// -1 表示尚无父结点或没有孩子

每轮找两个尚无父结点的最小根，再新建父结点。

n 个叶子、n−1 个内部结点，共 2n−1 个结点；这不保证是 D008 所说的满二叉树。

教学注记

有两个孩子的内部结点不代表每层都填满。编码从叶子沿 parent 回到根时，先收集的是末位，最后须反转。代码检查整数溢出与固定容量。

算法代价

树最优了，实现就一定快吗？

工作本演示实现代价（n 个符号）
每轮选两个最小根扫描尚未被合并的根单轮 O(n)，构树 O(n²)
从叶子生成码字沿父链接回溯再反转总计 O(Σℓᵢ)，最坏 O(n²)
译码逐位沿树走，到叶子回根O(L)，L 为输入位数

最优 WPL 描述编码目标；构造算法的运行成本是另一件事。

教学注记

若用最小优先队列，构树可做到 O(n log n)，堆的机制留待 D020。存树 O(n)，若保存所有码字，最坏需要 O(n²) 字符。本课固定容量仅服务小规模演示。

译码与边界

收到 010110111，怎样还原消息？

读入片段走到的叶子动作
0A输出 A，回根
10B输出 B，回根
110C输出 C，回根
111D输出 D，回根

结果为 ABCD。若输入在 11 处结束，停在内部结点，应报告码字不完整。

教学注记

码表是第 12 页那一份。前缀编码不自动检测所有传输错误：一个比特翻转可能仍译成合法序列。不能把“可以译码”说成“能够纠错”。

适用边界

少了 4 bit，就一定让文件更小吗？

本例内容从 32 bit 降到 28 bit，节省 12.5%。

  • 解码端还需要知道码表或树。
  • 文件可能包含长度、头部和字节对齐填充。
  • 短消息的额外开销可能超过节省量。

哈夫曼在给定权值的二元逐符号前缀编码中最优，不表示对所有压缩方法或完整文件都最优。

教学注记

码表需与当前编码一致。单符号字母表的结构深度是 0，本演示约定码字为 0，于是线上码长为 1，另行处理。零频符号本演示拒绝，可在建模时移出字母表。

独立学习证据

换一组频率，你能独立优化结构吗？

四种事件 P、Q、R、S 的次数为：5、2、1、1
  1. 手工完成每轮最小合并，画出编码树。
  2. 给出码字、WPL 与平均码长。
  3. 与每个符号 2 bit 的方案比较，并说明优化的量。
教学注记

保留 7 分钟独立作答、2 分钟核对。合并权值 2、4、9，WPL=15，平均 15/9=5/3；等长为 18。一个可行码表 P=1、Q=00、R=010、S=011。并列情况下允许其他最优结果，判定须包含前缀性、每轮选择和代价，不要求码字逐字相同。
