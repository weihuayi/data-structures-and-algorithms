# D004｜链表与表示的选择

## 本质关系

链表 = 放弃物理相邻，用显式链接表达"前后相继"。表示不变量换形态：从"第 i 个元素恒在 base+(i−1)×L"变为"从 head 沿 next 走 i−1 步到达第 i 个元素"；访问 O(1)→O(n)，插入删除 O(n)→O(1)，代价严格互换，强项与边界仍来自同一个原因——布局选择。链接要付空间与内存管理责任（每结点一个指针，malloc/free 配对）。收口在"没有最好的表示，只有适合任务的表示"与"抽象对象与物理表示分离——表示是服务抽象对象的方式，不是对象本身"。

## 接口方向

- **教材锚点**：《数据结构（C语言版）（第3版）》2.5–2.8——链式存储结构定义、结点结构、单链表操作实现；2.8 一元多项式相加作为习题路径。
- **生活连接**：寻宝游戏——每条线索只写着下一个地点，必须从第 1 张纸条走起；与 D003 快递柜恰成反例对（柜号算位置 vs 线索沿着走）。
- **工程连接**：工序链（每道工序只登记下一道）。火车车厢挂摘类比已于 2026-09-22 删除（9/21 课堂上教师判断其不够贴切）。
- **数学接口**：递推数列 = 首项 + 递推关系 ↔ head + next；第 i 项只能逐项推出。
- **实践种子**：内存泄漏与内存管理责任；双向链表多付一个指针换反向自由。
- **回收 D002**："先预测、再运行、再检查"的课堂口径；双索引扫描的思想迁移为两个有序链表合并中的双指针（D002 只在同一序列内讲双索引扫描，从未讲两个序列的合并——这里是思想迁移，不是原文回收）。
- **回收 D003**：内存模型（内存是字节数组、指针是记录地址的变量）、表示不变量、O(1)/O(n) 代价对照、稀疏多项式留问、"没有最好的表示"。

## 主要教学目标

- 能说出结点设计（数据域 + 链接域），理解次序由显式链接而非物理相邻表达；
- 能解释访问为何退化为 O(n)，并写出新形态的表示不变量；
- 能画出插入改两个链接的正确顺序（先接后继、再改前驱），说明断链陷阱与 free 的责任；
- 能根据操作模式（增删频繁 vs 访问为主、规模不定 vs 稳定）选择顺序表或链表。

## 主要问题

- 只给真正存在的项安排住处，次序怎么保？
- 结点在内存里住成什么样？malloc 出来的结点地址相邻吗？
- 取第 i 项要走几步？插入、删除各改什么？
- 顺序表 vs 链表，代价为何严格互换？什么时候用哪个？

## 主要案例

稀疏多项式（回收 D003 留问，只给非零项住处）、寻宝游戏（线索 ↔ next，与快递柜成反例对）、按学号插入新同学的名单（这次不用搬家）、两个有序链表合并（承接 D002 双索引扫描的思想迁移）。
