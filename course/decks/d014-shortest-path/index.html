少走几条边，就一定更快吗？

路线一：A→B→E，两条边。

路线二：A→B→D→E，三条边。

分别计算通行时间，再判断广度优先搜索（BFS）保证哪一种“最短”。

核对答案与理由

A→B→E：3+7=10。

A→B→D→E：3+1+3=7。

BFS 保证最少边数。每边代价相同且非负时，它也能保证最小累计代价。

第一部分 · 我们要求哪一种最短？

从一个起点出发，我们究竟要求什么？

教材定义（概述）
给定带权图及源点，求源点到其他各顶点的最短路径。带权路径的长度用沿途边权之和度量。

输入：\(G=(V,E,w)\)，源点 \(s\)。

路径 \(P\) 的代价：\(\ell(P)=\sum_{e\in P}w(e)\)。

最短距离：\(\delta(s,v)=\min_{P:s\leadsto v}\ell(P)\)。

输出：每个顶点的最短距离，及一条对应路径。

源点到自身：距离 \(0\)。

没有到达路径：距离记为 \(\infty\)。

本讲重点：有限图、固定非负边权。无向边可按两个方向读取；有向边按箭头读取。

找到一条路线后，哪些事情还没有确定？

已经找到 A→C→D，长度为 7。

这条记录说明：

  • 到 D 的最短距离至多为 7。

能够直接断定最短距离就是 7 吗？

核对答案与理由

还需要比较其他可能的路线；到 D 的距离仍然可以改进。

第二部分 · 距离的改进与确认

找到更好的路线，怎样修改已有记录？

原记录：A→C→D，长度 7，D 的前驱为 C。

新路线：A→B→D，长度 3+1。

距离和前驱分别要怎样修改？

这里先作局部路径比较，完整执行顺序稍后建立。

核对答案与理由

到 D 的距离：7 → 4。

D 的前驱：C → B。

保留更短路线的长度，同时保存它的最后一步来源。

第二部分 · 距离的改进与确认

一条输入记录怎样产生新的候选？

已有路径信息到 B 的路线长 \(\mathrm{dist}[u]=3\)
读取的图记录边 BD 存在，权为 \(w(u,v)=1\)
新候选路径经 B 到 D，长度 \(3+1=4\)
与旧值比较旧记录 \(\mathrm{dist}[v]=7\)；\(4<7\)，接受候选

松弛（Relaxation）：用一条新候选路径尝试改进距离。

u 是本次延伸的出发顶点，v 是待改进顶点；本例 \(u=B,v=D\)。dist[v] 保存当前找到的最好距离。

\(\mathrm{dist}[v]\gets\min\{\mathrm{dist}[v],\mathrm{dist}[u]+w(u,v)\}\)

u 是新候选路径的前驱；仅在接受更短候选后，才写入 parent[v]=u。

图、距离、前驱和确认状态各保存什么？

顶点编号：A=0，B=1，C=2，D=3，E=4。

原图边的存在性、方向与权值
dist[v]当前找到的最好路径的长度

第二部分 · 距离的改进与确认

一条更短的路线，必须先经过哪里？

在一般的一轮选择前，设集合 \(S\) 中的距离已正确确认，且邻居已完成更新。

沿任意一条从源点到外部顶点的路线，找：

第一个未确认顶点 \(y\)，及它之前的顶点 \(x\in S\)。

处理 \(x\) 时，边 \(x\to y\) 已经参与更新。

x、y 由所讨论的路线决定；首次出界就到终点时，也可以 y=u。

第二部分 · 距离的改进与确认

为什么边权非负，就能够确认当前最小者？

选最小有限候选 \(u\)（图中 D）。假设从 \(s\) 到 \(u\) 的路径 \(P\) 满足 \(\ell(P)<\mathrm{dist}[u]\)。

已更新\(\mathrm{dist}[y]\leq\ell(P_{s\leadsto y})\)
dist[x] 已正确，且处理过边 x→y。
非负权\(\ell(P_{s\leadsto y})\leq\ell(P)\)
后续边权非负。
矛盾\(\mathrm{dist}[y]<\mathrm{dist}[u]\)
选择规则却给出 dist[u]≤dist[y]。

因此可以确认 u。 哪一步用到了非负权？权为 0 时仍成立吗？

第二部分 · 距离的改进与确认

出现负权边后，哪里会失效？

从 s 出发，先得到 \(\mathrm{dist}[p]=2\)、\(\mathrm{dist}[q]=5\)。

若先把 \(\mathrm{dist}[p]=2\) 当成最短距离确认，会遗漏什么？

请指出上一页论证中失去保证的那一步。

核对答案与理由

s→q→p 的长度为 5−4=1。

到 q 的前缀长 5，整条路径反而只长 1。

延长路径可能降低代价，原来的确认依据失去保证。

第二部分 · 距离的改进与确认

怎样把这些判断组织成完整算法？

dist[s] = 0，其余为 ∞；parent 为空
所有顶点初始未确认
重复：
    选取暂定距离最小的未确认顶点 u
    若不存在有限候选，停止
    确认 u
    对 u 的每个未确认邻居 v：
        若经 u 的路径严格更短：
            更新 dist[v] 和 parent[v]

迪杰斯特拉算法（Dijkstra）

选择规则由当前距离给出。

确认理由依赖非负权。

邻居更新为下一轮积累信息。

源点距离 0 是起点。教材把确认源点及其初次邻居更新并入初始化，后续过程相同。

第四部分 · 任意两点之间的距离

为什么先固定 k，再检查所有顶点对？

弗洛伊德算法（Floyd）：逐步扩大允许的中间顶点集合。

for k = 0, ..., n-1:           // 本阶段新增允许的中间点
    for i = 0, ..., n-1:
        for j = 0, ..., n-1:
            若两段路径都存在：
                D[i,j] = min(D[i,j], D[i,k] + D[k,j])

k 是阶段变量；i、j 枚举该阶段的全部端点对。

\(n\) 个阶段，每阶段 \(n^2\) 对：时间 \(O(n^3)\)，距离矩阵空间 \(O(n^2)\)。

本讲沿用非负权范围。完整矩阵推演及各对路径的恢复留作教材阅读。
