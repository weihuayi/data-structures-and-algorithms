# D014｜最短路径：距离怎样更新，何时确定？

## 设计卡：本质关系

本讲以非负权图的单源最短路径为主线，先预测输出的距离与前驱表示，再通过完整执行和分层证明，建立“已有路径支持暂定距离、读取新边形成候选、比较改进距离、依据条件确认最短距离”的关系。Dijkstra 是主要算法；Floyd 用于解释查询扩大到任意两点后，如何按允许的中间顶点集合组织计算。

2026-10-30 形成 HTML 初稿，2026-10-31 接入课程共性约定与共享导航、任务工作区。课件初版按五轮交互讨论及压力测试组织为四部分、36 页，经课后重构及本次 Floyd 认知桥梁补充，现为 38 页。页面数量服务于认知职责、同屏比较和逐步展开；课堂时间按解释、推演、作答、反馈及运行活动估算，不由页数换算。课堂效果与实际时间尚需排练及学生表现校准。

核心判断：

- 有限暂定距离有一条实际路径支持，是最短距离的上界；首次找到路线不等于已经确认最短距离。
- 确认依据在每次选择下一顶点前使用：已确认距离正确、其邻居已完成更新；沿假设更短路径的首次出界位置，结合非负权得到矛盾。
- 输入图、距离、前驱与确认状态分别承担职责；确认顶点与完成邻居更新是不同阶段。
- Floyd 当前矩阵受允许的中间顶点集合限制，阶段最优与最终全局最优需要区分。

## 案例与学习证据

主例为本讲自拟带权无向图，A–E，源点 A：

`AB=3，AC=2，BC=2，BD=1，CD=5，BE=7，DE=3`。

顶点标签与 D013 相同，但输入边与权值独立定义，不能沿用 D013 原数据。

| 案例或活动 | 可核对结果 | 教学作用 |
| --- | --- | --- |
| 主例单源 | 确认顺序 A、C、B、D、E；距离 A=0、B=3、C=2、D=4、E=7 | 暂定改进、最小候选与确认 |
| 主例路径 | 到 E：A→B→D→E，权和 7 | 前驱变化与路径恢复 |
| BFS 对照 | 两边路线 A→B→E 为 10；三边路线 A→B→D→E 为 7 | 最少边数的边界 |
| MST 对照 | AC、CB、BD、DE 总权 8；树上 A→B 为 4，原图直接 AB 为 3 | 全树目标与路径目标 |
| 处理 B 的输入 | 矩阵 B 行检查 5 个位置；邻接表枚举 A、C、D、E 四项；D:7→4、E:∞→10 | 输入来源、更新与代价 |
| 有向独立图 | P→Q=4、P→R=1、R→Q=2、Q→S=0、R→S=6；P 到 S 为 3，路线 P→R→Q→S | 有向读取、零权与确认 |
| 反向查询 | S 没有出边，S 到 P 不可达 | 忽略箭头时正向答案仍可能相同，需额外检查方向 |
| 不可达变式 | 删除 BE、DE；确认 A、C、B、D 后停止，E 保持 ∞ | 过程中的未知与结束后的不可达 |
| 零权等长 | AB=0、AC=1、BC=1；A、B 的距离均为 0，到 C 可以有等长路线 | 非递减确认及记录一条路径 |
| 负权反例 | s→p=2、s→q=5、q→p=−4；经 q 到 p 为 1 | 非负权论证的边界；C 演示拒绝负权输入 |

- 零权与无边分开。Python 用 None 表示未知标签；C 用 present 保存存在性、INF 表示不可达标签，并预先限制整数范围以保护加法。
- 只在严格更短时修改前驱，记录一条路径，不宣称路径唯一。源点没有前驱但距离为 0；恢复路径先检查是否可达。
- 作答与核对期间保留题目、图、矩阵/邻接项、条件和初始状态；提示及答案默认折叠，展开作为补充。打印保留问题，答案保持隐藏；打印只保留播放器当前状态。
- KaTeX、样式与脚本均使用仓库本地资源。课堂演示不依赖外网。
