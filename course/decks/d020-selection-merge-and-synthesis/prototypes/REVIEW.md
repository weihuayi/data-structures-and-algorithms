# D020｜R8→设计落地压力测试记录（教师审阅候选）

> **范围**：教学设计卡、34 页候选 Storyboard、3 个隔离原型及其确定性验证。**不是已完成 90 分钟真实排练的报告。** 默认所有评审问题仍需教师确认。

## 一、专业正确性及高风险判断

| 检验项 | 预期依据 | 当前结论与待验 |
| --- | --- | --- |
| 堆的形状和堆序 | 最大堆父不小于子；数组代表完全二叉树 | 状态生成器断言每次建堆完成和提取后有效前缀满足堆序；正式图中还需人工查父子位置 |
| 向下调整前置条件 | 两个孩子子树必须先合法 | 错误输入 [2,5,7,3,4,6,8] 从根一次下沉可得 [7,5,8,3,4,6,2]，仍不合法；错误分支不混作正常算法路径 |
| 同一输入可能有多个合法堆 | 具体建堆顺序控制轨迹，而堆序本身不是全序 | P1 要求“按 i=2,1,0 自底向上”，据此可以核对确定轨迹；一般合法堆判定不等同于匹配唯一数组 |
| 稳定归并 | 左右来自同一原始序列连续分段；相等先取左 | P2 包含 2甲、2丙和原位置说明；测试对相等关键字和记录身份保留进行检查 |
| LSD 基数 | 补零、由低位到高位、各轮稳定桶收集 | 10 条教材候选记录的个／十／百位结果作为金样例；正式链式实现还需核验 head/tail/next 语义 |
| 算法复杂度 | 统一成本与模型前提 | 教学设计卡已限定比较排序下界、数组堆与归并空间、LSD 的数位和基数条件；未以原型执行时间代替复杂度证明 |

## 二、主例与学生证据压力测试

| 责任 | 强制保留 | 降级时可压缩 | 学生理解的风险 |
| --- | --- | --- | --- |
| G1／P1 | 独立堆构造或修复，解释两个子堆前提及有效堆前缀 | 重复演示其它堆输入、严格线性建堆级数证明 | 只记交换过程，误以为从根下沉任意数组 |
| G2／P2 | 两个有序输入的首候选、原记录身份与稳定相等取左 | 多个递归树、额外算法比较表 | 把归并仅看成重新排序，忽视前缀不变量 |
| G3／P3 | 真实桶号、桶内 FIFO／链接与收集顺序 | 课堂全部三位数全部轮次的逐键播放，完整 C11 链表实现 | 只有最终数组，看不到教材所需“分配与收集”过程 |
| G4／P4 | 至少两种方案、约束改变后的理由 | 生产级排序库性能案例、严格下界阶乘推导 | 仅凭大 O、无条件选最快 |

**决策**：原型特意不对全班播放 10 条教材记录的每一个入桶动画；课堂可将 4 条示范用于建构，再让学生用不同的四条记录独立完成一轮，并把教材 10 条的完整三轮留给课后深化。任务范围和正式 A/B 作业需教师确认。

## 三、时间模型的算术检查

### 模型 A：90 分钟有效教学

| 阶段 | 教学责任分钟 |
| --- | ---: |
| S0 排序契约 | 5 |
| S1 选择与树形选择导航 | 6 |
| S2 堆排序 | 27 |
| S3 阶段检查点 | 4 |
| S4 归并 | 18 |
| S5 链式基数 | 14 |
| S6 比较与选择 | 8 |
| S7 收束与作业 | 3 |
| **已分配教学责任** | **85** |
| **第一段机动** | **3** |
| **第二段机动** | **2** |
| **合计** | **90** |

自然断点：前半 5+6+27+4+3=45，后半 18+14+8+3+2=45。**P1–P4 作答时间已包含在所属阶段，不允许再次单独加到 90 分钟之上**。

### 模型 B：实际课堂延迟的压力测试

这不是实际计时结果，而是假设偏差模型：
- P1 堆 5 分钟独立作答中出现共性误解，补充解释 **+2 分钟**；
- P2 稳定归并出现记录身份混淆，补充解释 **+2 分钟**；
- P3 桶内 FIFO 出现错误，补充解释 **+2 分钟**；
- P4 选择方案解释不充分，补充反馈 **+2 分钟**。

结果：85+8=93 分钟教学责任，原预留 5 分钟机动仍**超出 3 分钟**。因此 90 分钟方案没有足够余量同时吸收四处典型错误；应优先删减重复示范与非核心推导，而不是取消理解检查。

### 模型 C：实际只剩 80 分钟有效教学

若课间从原 90 分钟扣去 10 分钟，候选降级分配为：

| 阶段 | 90 分钟原责任 | 80 分钟降级 |
| --- | ---: | ---: |
| S0 | 5 | 4 |
| S1 | 6 | 4 |
| S2 | 27 | 23 |
| S3 | 4 | 4 |
| S4 | 18 | 18 |
| S5 | 14 | 13 |
| S6 | 8 | 6 |
| S7 | 3 | 3 |
| 机动 | 5 | 5 |
| **合计** | **90** | **80** |

降级动作需明确对应页面：S1 压缩竞赛树第二个示例；S2 省去重复下沉状态但保留错误反例和 P1；S0 压缩熟悉的排序契约；S5 只示范一轮桶链接，P3 仍需做一轮；S6 P4 缩为一个有条件变化的问题。**不压缩独立作答到零**。

### 模型 D：尚未测到的真实耗时

缺少教师实际连续讲述、按钮点击与学生独立作答的计时记录；无法验证 34 页是否恰好对应上述预算。真实排练应按页面 ID 记录计划秒数／实测秒数／偏差原因，遇到连续 3 页超时应调整后续内容深度。不要仅统计总页数或把无学生作答的快速播放当作完整排练。

## 五、教师审阅建议与准入条件

目前可提交教学设计卡、候选 Storyboard 和关键原型供教师审阅。进入正式 `slides.py` 之前，优先确定：树形选择讲解是否过浅、链式基数示范如何覆盖 head/tail/next、90/80 分钟哪个是实有时间、独立 P1/P2/P3 是否足以暴露错误，以及 A/B 正式任务总负担。

## 六、QA-01–QA-08 的设计修订结果

- QA-01/02：将 E1a/E1b/E2/E3 嵌入对应机制页，P1–P4 不冒充覆盖全部理解。
- QA-03/04：前台四个 Section，后台 S0–S7 八个教学活动预算阶段；34 页，对堆边界、归并成本、基数稳定性和比较模型各明确单页主责。
- QA-05：总教学责任 85 分钟及机动 5 分钟不变。第 3 页为第一部分入口，第 4 页进行 D019 先修诊断；在项目实施中继续检验真实 90/80 分钟节奏。
- QA-06：树形选择保留比较结果可复用机制；链式基数保证 head/tail/next 与桶内 FIFO 解释；课堂 P3 仅独立完成四条新记录的一轮。
- QA-07：数学、记录身份、堆有效边界、归并指针与基数桶次序的契约进入设计卡；正式 CourseDeck 另行验证。
- QA-08：A/B 备选最低必做范围已收敛并声明与 D019 同周总负担，正式作业仅由课件最后一页发布。

以上是设计一致性结论。**没有真实教师排练、学生作答与课堂反馈证据。**
