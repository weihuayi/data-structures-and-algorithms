# D020｜第三轮综合准入质量检查（QA-09–QA-14）

> **受控审阅分支**：PR #56（视觉一致性）与 PR #57（认知接续）均为尚待教师审阅的前置 PR；本轮基于 PR #57 已核验的 34 页课件实施，**不直接修改 main，不擅自合并**。本文件既记录发现的问题，也界定尚未完成的真实教学验证。

## 一、评审角色、第一性原理与准入边界

评审视角：数据结构与算法（数学定义、算法不变量、计算模型）、计算机科学教育（诊断与迁移的真实证据）、学习科学（认知负荷、指导渐退、形成性反馈）、科学计算软件质量保证（独立参考实现、边界用例、重现性）。

第一性原则：

1. **专业判断来自输入—前提—操作—不变量—结果—代价的闭环**，不由示例动画与讲解流畅性替代。
2. **学习目标必须对应可观察的独立行为**；运行测试通过、学生复制结果、展开正确答案均不是形成理解的证据。
3. **视觉表示必须把学生实际需要观察的计算关系显化**，而不只是制作了图；原始数据、操作位置、保持关系与结果应可核对。
4. **教学时间必须包含思考、提问、反馈和状态恢复**；页数与讲师朗读速度不足以推导真实课堂用时。
5. **工程测试、教师试讲、课堂实施和学生掌握是不同证据层**；不因任一前者成立声称后者成立。

相关实践参考：Carnegie Mellon Eberly Center 的 [Learning Principles](https://www.cmu.edu/teaching/principles/learning.html) 和 [Learning Objectives](https://www.cmu.edu/teaching/designteach/syllabus/newcourse/learningobjectives.html)，[Waterloo 教学目标—评价—活动对齐指南](https://uwaterloo.ca/centre-for-teaching-excellence/catalogs/tip-sheets/aligning-outcomes-assessments-and-instruction)，AERO [Explicit Instruction Guide](https://www.edresearch.edu.au/guides-resources/practice-guides/explicit-instruction-practice-guide-full-publication)。这些指导原则是方法依据，并非 D020 已获得学习效果证据。

## 三、已执行的独立专业核验与发现

### QA-09/10 · Javascript 独立比较参考

使用可复现的种子 20261124：堆 1,288 组（长度 0–45，负数与相同关键字），稳定归并 900 组（有序左右输入、记录身份），基数排序 600 组（二/十/十六进制、重复键、多轮数位）。与按数值排序后的多重集、使用原始记录下标的稳定排序、使用低位前缀的稳定排序交叉检查，**全部一致**。加入单次根下沉非法前提、乱序归并输入、负整数基数和数位不足的拒绝测试。

**边界**：这些测试验证有限输入集合和参考模型，不能证明复杂度渐近公式；数值范围、JavaScript 数值精度和 C11 输入类型不同，必须分别声明。

### QA-09/10 · C11 原示例发现并修订

**已发现程序可靠性缺口**：链式 LSD 演示原使用 \`int divisor\` 且每位结束执行 \`divisor *= 10\`，输入较多十进制数位可能导致有符号溢出；而 \`next[32]\`、\`out[32]\` 为固定缓冲区，原先没有明确拒绝 \`n>32\`、负关键字和数位不足。4 条两位数的课堂主例虽不触发这些问题，但不能据此将示例称为无条件适用的排序函数。

已将分桶函数限定为 **0–32 条非负 C int 关键字**、位数足以覆盖最大输入且不超过该类型的最大十进制位数，用 \`unsigned long long divisor\` 并避免最后一次无用乘法。增设独立 C11 参考测试，涵盖 \`INT_MIN/INT_MAX\` 堆、重复键稳定归并、\`INT_MAX\` 十位十进制 LSD、32 条记录上限、空输入等；编译与 UndefinedBehaviorSanitizer 结果以 CI 记录为准。

### QA-11 · 学习任务的证据与反事实压力

| 最低任务 | 主要评价对象 | 核对要点 | 可能误判的情况 |
| --- | --- | --- | --- |
| P1 堆（第 14 页） | 操作 + 前提解释 | i=2/1/0 的特定调整轨迹、最大根、extract 后 heapSize=6 | 只报出合法堆却无法解释每次下沉的前提 |
| P2 稳定归并（第 20 页） | 操作 + 记录身份与正确性解释 | L/R 各自有序、原始左连续段早于右段；相等时取左 | 仅输出有序数值，不保留 id 或解释稳定性 |
| P3 基数（第 28–29 页） | 一轮操作 + 高位反例解释 | 桶头尾与 FIFO、个位结果；十位桶的 21→22 倒序反例 | 会把元素入桶，仍无法解释为什么多轮 LSD 必须稳定 |
| E3 成本模型（第 31 页） | 条件解释 | 堆 O(1) 辅助空间的迭代条件；比较下界仅属于比较决策树最坏比较次数 | 把下界当全部排序的运行时间下界 |
| **P4（第 32 页）** | 新情境条件化选择 | **A/B 为最低课堂必答**：小整数键域下稳定 LSD/归并；任意可比较键下稳定归并，说明方案随输入条件而变 | 过度要求学生在 5 分钟内同时掌握新最小堆 Top-k 方法 |
| P4 C（拓展） | 已知堆对偶的条件迁移 | 仅取 k 条较大记录，不要求全排序；相同关键字的 k 条可任选；最小堆 O(n log k)（k≥2） | 未说明稳定性、重复键边界或将其误作必达学习目标 |

**建议现场 0/1/2 记录规则**：0＝无法给出正确结果或关键条件；1＝结果基本正确但理由或前提缺失；2＝结果、关键条件和依据都明确。教师或助教应尽可能收集部分独立答案与共性错误，但不能用少量样本直接宣称全班 129 人已掌握。上述是建议的评价量规，**不是已生成的学生成绩**。

### QA-12 · 三组图示的认知一致性

- **堆**：树图和 0 起数组表达同一状态；观察交换双方、heapSize 边界、已排序后缀；反例作为非法前提另行标记，不假装是合法轨迹。
- **归并**：固定原始有序左右输入；动态 i/j 候选与输出前缀；相等键时记录身份必须持续在场。
- **基数**：桶号、桶内进入顺序、收集后记录 ID、链式 C11 \`head/tail/next\` 的语义要对应；JavaScript 的桶数组可用于视觉模拟，但不等于 C11 已真实生成某链式内存布局。
