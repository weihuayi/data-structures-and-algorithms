# D020｜R2 表达路径与认知接续压力测试

> 历史记录：本报告描述当时 R2 版本。2026-11-25 R13–R18 已替换第 5–7 页的最值方向转换方案；现行设计见本讲 README、Storyboard 和修订记录 R13–R18。

> **定位：** 本文件是针对 D020 正式 34 页内容的第二轮教学表达质量评审记录。PR #56 是视觉一致性基线；本轮只修订 D020 的认知表达和对应的 Storyboard，不扩展算法目录、不修改共享课程组件。**自动测试不等价于学生学会或教师确认。**

## 一、评审角色、依据与方法

评审视角为数据结构与算法（专业正确性、不变量、计算前提）、计算机科学教育（先修与概念形成、课堂独立证据）和幻灯片教学表达（页面职责、可视化信息密度和跨页路径）。依据一是排序算法的输入契约—表示—机制—不变量—工作量关系；依据二是 Carnegie Mellon Eberly Center 关于先修知识激活、目标—活动—评价一致性的教学原则，以及 Waterloo 的对齐指南与 AERO 的显性示范—逐渐撤除支架原则。此处将其转化为候选检查标准，并不将其作为已证实的课堂效果。

- [Carnegie Mellon：Learning Objectives](https://www.cmu.edu/teaching/designteach/syllabus/newcourse/learningobjectives.html)

## 二、质量标准与阻断级别

| 标准 | 需要验证的事实 | 判定问题 |
| --- | --- | --- |
| **C1 动机** | 前一算法或表示暴露了什么实际限制？本页新机制解决哪一种重复工作？ | 读者能否回答“为什么此时讲这个” |
| **C2 术语时机** | 在首次推演前给出中文名、必要英文名、语义与输入范围 | 不允许先用未定义的符号/操作/算法名称要求学生证明 |
| **C3 先修可达** | 依赖知识已在前页建立，或本页明确“回顾 D0xx”并补足最小必要内容 | 不把教师知道与学生真正会用相混同 |
| **C4 单页主责** | 一个主要推理/辨认/预测任务，其余信息仅作为条件或证明辅助 | 避免同页并列引入多个独立未学概念 |
| **C5 正确性条件** | 操作前提、状态边界、主例及反例、相等元素规则、复杂度模型明确 | 条件不充分或以非法输入证实算法必然正确均判阻断 |
| **C6 独立证据** | 明确输入、预测/解释问题与完整可核对答案；默认不泄露 | 正确推演 ≠ 理解证明 ≠ 条件迁移 |
| **C7 认知接续** | 下一页承接前页形成的结果，引入新层级而非重复或跳跃 | 如最小值前缀→最大值后缀、局部归并→递归归并 |
| **C8 表达负担** | 首要问题可读，数据/变量/图例持续可访问；不以缩字换取空间 | 默认/答案展开/动态轨迹均要检查，保留课堂机动余量 |

**P0 阻断：** 数学或算法机制错误、必要前提缺失、同页独立任务答案事先泄露、学生在未学习的算法上被要求完成迁移、前台出现教师后台执行指令。**P1 必须处理或说明：** 概念首次定义滞后、机制方向或条件跨页断裂、页面职责重叠、缺少可复核中间状态。**P2 可按实际页面处理：** 不影响正确性与认知的非核心措辞、局部留白。

## 四、R2 实施决策与避免的新问题

| 风险与页面 | 修订后的教学表达 | 准入判断 |
| --- | --- | --- |
| R2-01 · 05–08 | 简单选择取最小值入左前缀；从竞赛树复用比较引出最大值入右后缀，再正式定义最大堆 | 不能把“最小”突然改成“最大”却不解释升序目标保持不变 |
| R2-02 · 08–11 | 最大堆先用父子自然语言定义，再在数组页定义 heapSize 与下标公式；siftDown 在首次操作页命名并说明两个孩子子树已成堆 | 数组公式不得出现在数组表达建立之前 |
| R2-03 · 11–16 | 建堆演示补 i=2/1/0 中间状态，P1 的折叠答案给出同一固定过程；反例明确失效前提，检查页剔除“教师机动时间”等后台安排 | 新输入独立任务所需的操作机制必须已展示，且完整答案可核对 |
| R2-04 · 18–23 | 第 18 页命名局部归并 merge；第 22 页才由递归引出归并排序 merge sort；保持/耗尽两分支明确 | 操作的正确前提应先于整体递归归并的证成 |
| R2-05 · 25–29 | 数位结构 → 基数排序与 LSD 定义 → 个位/十位 FIFO → 链式桶 → P3 一轮独立任务 → 倒序反例与 d、b 代价 | 比较下界不能抢先承担数位排序的动机；P3 不应顺带给出下一轮答案 |
| R2-06 · 31–32 | 首先说明“比较”和“数位”两种输入信息，再诊断比较下界；P4 A/B 使用已学 LSD/归并，C 给出最小堆对偶定义 | 不要求学生事先知道稳定计数排序或 Top-k 最小堆实现 |
| R2-07 · 33–34 | 回收三类机制的输入—保持—适用条件；末页沿用视觉基线的 A/B 正式作业结构 | 本轮不擅自改动作业题量和课程共享组件 |
