## 一、教学中心与专业范围

**主问题**：面对相同排序任务，能否通过维护结构、组合有序序列、利用关键字表示，减少重复工作；不同机制的正确性、代价与适用条件如何判断？

**主要认知跨越**：从对单个排序算法执行步骤的掌握，发展到理解“有效信息—维护／利用机制—正确性—代价—条件化选择”的关系。它不是单纯记忆性能表；不把复杂度阶相同视为工程行为相同。

- **排序契约**：关键字、完整记录与记录身份分离；正确输出满足有序、排列保持、终止；稳定性是可能的附加约束。重复关键字在图示和测试中保留身份。
- **选择排序（8.4）**：简单选择的每轮最大值右端就位和二次比较代价；树形选择（竞赛树）复用胜者路径信息的机制导航；二叉最大堆的形状与堆序、数组表示、建堆、向下调整、重复取最大值完成升序。
- **归并排序（8.5）**：两个有序子序列的首候选选择、输出前缀不变量；递归分解和线性归并；稳定合并规则；标准数组实现的辅助空间。
- **基数排序（8.6）**：最低位优先（LSD）示例、多关键字次序、链式桶的稳定分配与收集；复杂度必须声明数位数量、基数和每轮分配成本。利用整数范围的计数排序可在教师专业支撑中补充，但不作为 D020 的独立学习达标要求，不能取代教材链式基数排序。
- **统一判断**：区分比较排序的决策树下界与关键字受约束时的非比较排序；按时间、额外空间、稳定性、输入特征、范围和任务输出选择算法；Top-k 不等于必须完整排序。

**深度边界**：自底向上建堆 \(\Theta(n)\) 的严格求和、决策树下界完整证明、工程级 in-place merge、生产级基数排序与外部排序败者树／置换选择，作为教师专业支撑或自学导航；不以课堂完成严格证明为达标必要条件。教材 8.4.2 树形选择不能被完全遗漏，8.6 链式分配／收集不能降格为仅展示最终结果。

## 二、先修、输入与正确性约定

- D003/D008：0 起连续数组及完全二叉树形状；`left(i)=2i+1`、`right(i)=2i+2`（需检查下标是否小于有效堆大小）；D017：BST 全局左右顺序与 AVL 平衡不同于堆的父子堆序；D006：递归与子问题；D019：有序、排列保持、稳定性、插入前缀、快排划分——**只作设计接口，不假定已经实际学会**。
- 主例均以升序排序为目标。二叉最大堆定义：完全二叉树且各父结点关键字不小于孩子；数组的有效堆范围是 `[0, heapSize)`，排序后缀是 `[heapSize,n)`。相同关键字的调整规则须明确，以免将某一确定轨迹当成唯一合法堆。
- `siftDown(i,m)` 的前提：`i` 的两个孩子子树已是最大堆；任意无序数组不能仅在根调用一次 `siftDown` 就宣称完成建堆。
- 标准稳定归并：左右子序列来自原记录序列连续的左／右范围，且各自已按关键字稳定排序；关键字相等时先取左边。两个来源完全独立且无共同初始次序时，跨来源“稳定”需额外定义。
- LSD 基数排序：对非负整数关键字补足相同位数，低位到高位；每轮在各桶中保持输入顺序，按桶号依次收集。独立的记录 ID 不随移动丢失。
- 成本口径区分比较、记录移动、数组读写、临时存储与真实耗时；常见数组实现的简单选择 \(\Theta(n^2)\) 比较、堆排序最坏 \(\Theta(n\log n)\) 时间及迭代实现 \(O(1)\) 工作空间、标准归并 \(\Theta(n\log n)\) 时间和 \(O(n)\) 辅助存储、LSD 基数 \(O(d(n+b))\) 时间与实现相关空间。树形选择与基数不作无条件优越性主张。

## 三、G1–G4 学习目标与最低独立证据（QA-01/02）

**检验原则：操作推演、正确性解释、跨条件迁移是不同证据。** 不能用一次动画跟随或代码运行证明完整目标达成。短诊断 E1a/E1b/E2/E3 嵌入对应机制页，不额外增加大规模课堂练习。

| 目标 | 学生能够独立完成的行为 | 最低证据及页面 | 不成立的替代推断 |
| --- | --- | --- | --- |
| **G1 选择与堆机制** | 区分简单／树形／堆选择所复用的信息；按声明规则建最大堆、提取一次堆顶并解释前提和已排序后缀 | **E1a** `tournament-bridge`：解释复用胜者路径与重新扫描的差异；**P1** `heap-independent`：新输入完整建堆；**E1b** `heapsort-boundary`：独立指出堆前缀和已排序后缀分别保持什么 | 正确堆数组不等于理解堆排序不变量 |
| **G2 有序归并与递归** | 完成含重复键的稳定归并并说明输出前缀；判断递归为何能满足每次 Merge 的有序输入前提 | **P2** `stable-merge-independent`：保留记录 ID，独立取左规则；**E2** `merge-recursion`：解释两个子问题先排序、后归并的正确性依赖 | 会合并两个有序序列不等于理解递归组合 |
| **G3 代价与非比较边界** | 按工作量解释时间、空间、稳定性和比较模型条件；完成链式基数一轮稳定分配与收集 | **P3** `radix-independent`：桶内先后及收集结果；**E3** `comparison-model`：独立诊断两条有模型条件的复杂度陈述 | 基数操作正确不能证明具备复杂度分析能力 |
| **G4 条件化选择** | 明确数据契约、比较至少两种候选算法，说明约束变化后为何选择改变或不改变 | **P4** `choice-independent`：键域／空间／稳定性或 Top-k 条件发生变化后提出有依据的方案 | 背复杂度表不等于有条件的算法选择能力 |

**E3 最小诊断**：判断“堆排序总要申请一个长度 n 的临时数组”和“任何排序都不可能快于 n log n”是否无条件成立，分别指出标准迭代数组堆排序的额外空间、比较排序下界的计算模型。只需短独立判断与理由，不要求当堂完整证明。

最低成本认识：自底向上建堆为 Θ(n)；标准数组堆排序最坏 Θ(n log n)，迭代实现额外工作空间 O(1)；标准数组归并为 Θ(n log n) 时间和 O(n) 辅助空间；LSD 基数在 d 位、基数 b、桶寻址及记录移动常数成本模型下为 O(d(n+b))。注意比较排序的 Ω(n log n) 是互异键的通用比较决策树最坏比较次数下界，不能推广到受约束的整数分配排序。

P1–P4 和 E1a/E1b/E2/E3 均须先独立判断后核对；原输入、操作前提和结果始终可见。课堂没有实际全班作答证据时不能声明目标已达成。

## 四、主例、反例与阶段任务

| 用途 | 样例及要点 | 必需的核对 |
| --- | --- | --- |
| 堆的教师主例 | `[5,3,8,2,7,1,6]`，由无序数组自底向上建堆，再提取最大值；与三页隔离原型的输入保持一致 | 原输入尚非最大堆；结点下标、形状、建堆前提、完成后堆序与堆有效范围必须准确 |
| 堆的 P1 独立任务 | `[4,1,7,3,6,2,5]` 自底向上建堆：`[7,6,5,3,1,2,4]`，一次提取后 `[6,4,5,3,1,2 | 7]` | 每轮顺序固定为 i=2,1,0；说明“构造合法堆”不必只有一个数组答案 |
| 堆前提反例 | `[2,5,7,3,4,6,8]` 从根直接下沉可能得 `[7,5,8,3,4,6,2]`，仍非合法最大堆 | 标明**无序数组不可直接调用根调整** |
| 归并 P2 | 来自同一原始序列的连续左／右半段：`L=[2甲,5乙,8戊]`，`R=[2丙,6丁,7己]` | 输出 `[2甲,2丙,5乙,6丁,7己,8戊]`；相等取左 |
| 稳定性反例 | 简单选择对 `[2甲,2乙,1丙]` 的一次交换可得 `[1丙,2乙,2甲]` | 有序但不稳定；不能只看关键字 |
| 基数基础示例 | `[21,13,12,22]` 个位 → `[21,12,22,13]`；十位 → `[12,13,21,22]` | 各桶先进先出顺序不变 |
| 教材基数接口 | `[321,156,57,46,28,7,331,33,34,63]`，各关键字补齐三位 | 个／十／百位逐轮**分配、链结、收集**，不只报最终数组 |
| P4 综合选择 | 分别给出“0–100 整数成绩稳定排序”“任意可比较键、允许 O(n) 辅助空间”“仅求前 k 大（提供最小堆对偶条件）” | 先写数据契约，再选候选算法并给约束，防止机械配对 |

## 七、表达、工程和验证边界（QA-03/07）

**导航和活动分离**：前台四个认知部分——①简单／树形／堆选择与结构维护，②稳定归并与分治，③多关键字与链式 LSD 基数，④复杂度比较与条件化选择。后台 S0–S7 保留教学活动、检查点和时间预算；不得自动生成八组重复分节。34 页候选版包含四个部分起始页，大纲和分节由单一 Section 声明驱动。

**关键对象与符号契约**：

| 对象 | 约定 | 实现必须核对 |
| --- | --- | --- |
| 排序记录 | `key` 是关键字，`id` 是原记录身份，记录按主关键字非递减 | 重复键可区分身份；有序、排列保持和稳定性不混为一个性质 |
| 堆 | 0 起下标、父子关系 `2i+1` / `2i+2`；`heapSize` 是未排序前缀长度 | 数组／树结构同态；前缀 `[0,heapSize)` 与最终已排序后缀 `[heapSize,n)` 显示清楚 |
| 下沉与建堆 | `siftDown` 的两个孩子子树须先成堆；`buildHeap` 逆序从最后非叶结点调整 | 反例明确标非法；交换规则固定以便核对具体轨迹；不能把合法最大堆误认为唯一 |
| 稳定归并 | `L`、`R` 是同一原输入连续分割所得的有序部分，`i,j` 为未处理首位置，`B` 为输出 | 当前候选、输入剩余与输出前缀并存；相等时先取左；答案展开不丢输入 |
| 链式 LSD 基数 | `b` 为桶的基数，`d` 为数位数，数位不足高位补零 | 桶 0…b−1、`head/tail/next` 链接与 FIFO 收集次序必须显化，不只显示最终序列 |
| 数学代价 | `n` 记录数，`b` 基数，`d` 位数；严格区分时间、比较、移动、额外空间 | O/Ω/Θ 首次用于分析时说明上界、下界与紧确界；数学式经 KaTeX，C11 标识保持代码语义 |
| 独立任务 | 必要输入、问题、作答、提示、完整答案分区 | 默认答案隐藏、无结果泄露；展开保持输入与可核对最终结构；错误分支区别于合法轨迹 |
