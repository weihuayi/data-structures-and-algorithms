# D009｜二叉树的遍历

## 设计卡：本质关系

系统访问的设计：树的链接确定可走关系，任务仍需规定访问顺序。访问是明确的局部操作，不等同于递归进入或返回。先序、中序、后序共享递归结构，差异在于根相对于左右子树的访问时机；层序采用按层推进方式，由 FIFO 队列保存已发现而未访问的结点。显式栈保留为扩展阅读，不占主线页面。

反向看，普通遍历序列只保留部分结构信息。互异且相容的先序、中序通过“定位根、划分左右、递归恢复”唯一确定二叉树。恢复任务检验学生是否理解子树范围、左右位置及序列的生成规则。

主要认知跨越为 OPS、ALG、COR：从知道树结构转向设计访问顺序，解释不重、不漏与终止。INF、INV、COST 只作支撑。设计依据为课程认知主线 v0.2、D001–D020 Matrix v0.1 的 D009 条目、WhyOS 课程理解 Memo v0.3，以及仓库 Deck 修订指南；不改变矩阵或将设计依据当作学习达成证据。

## 主要问题与案例

问题链：为什么需要遍历 → 什么是遍历与访问 → 为什么有不同顺序 → N/L/R → 先、中、后序 → 统一递归结构 → 为什么成立 → 为什么需要层序 → 不同顺序服务什么任务 → 序列保留多少结构信息 → 先序与中序恢复。

1. **主例**：A 左 B、右 C；B 仅右 D；C 仅左 E。先序 ABDCE，中序 BDAEC，后序 DBECA，层序 ABCDE。根深度 0，高度 3，最大层宽 2。
2. **独立三序**：U 左 V、右 W；V 左 X、右 Y；W、X、Y 为叶子。先序 UVXYW，中序 XVYUW，后序 XYVWU。与恢复题形状不同。
3. **表达式应用**：`(a-b)*(c+d)`；先序 `*-ab+cd`，中序 `a-b*c+d`，后序 `ab-cd+*`。第 18 页用同一次减法 `− a b` / `a − b` / `a b −` 解释前缀、中缀、后缀：运算符分别位于操作数之前、之间、之后，操作数也可以是整个子表达式。三者分别对应先序、中序、后序。普通中序丢失结合关系，完全括号化为 `((a-b)*(c+d))`。求值需使用子树返回值，不能等同于打印后序。
4. **信息不足**：A 仅左 B 与 A 仅右 B，先序均 AB、后序均 BA，说明缺失位置也携带结构信息。
5. **恢复条件**：互异且相容。教师注记保留先序 ABC / 中序 CAB 的不相容反例，总集合相同不保证各轮分割相容。
6. **独立恢复**：先序 PQSRT，中序 SQPRT。P 左 Q、右 R；Q 仅左 S；R 仅右 T。后序 SQTRP，层序 PQRST。

### 实现与结论边界

- 输入指针必须表示有限合法树，遍历不检测任意指针图中的环或共享。非递归实现的存在也不表示能处理无限或非法输入。
- 固定容量 `CAP=32`，每个结点使用单字节标识。遍历输出不足时返回失败，输出中可能保留前缀；调用者必须检查返回值。
- 恢复函数要求 NUL 结尾字符串、互异标识和相容的分割；失败清空根与已用计数，不返回半棵树。结点存放在调用者的 `Tree` 池中，不可在构造后按值复制该结构，也不可返回已失效的局部池。
- 遍历的 Θ(n) 时间以单次访问 O(1) 为前提。递归/栈的 O(h) 和队列的 O(w) 是活跃辅助状态上界，不包括输出、输入树与本演示预分配容量。
- 恢复采用分段线性找根，最坏 O(n²) 时间、O(h) 递归辅助空间，另需保存 n 个输出结点。本讲不加入索引优化来转移教学重点。
