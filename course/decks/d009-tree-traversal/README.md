# D009｜遍历：系统访问的设计

## 设计卡：本质关系

树的链接确定了可走的关系，但没有替任务决定访问顺序。“访问”是一个明确的操作，递归进入、返回与访问结点需要分开理解。先序、中序、后序在相同的递归结构上安排不同的访问时机；显式栈与队列组织待做工作，从而形成不同的系统访问顺序。

反向看，一条输出序列可能丢失结构信息。互异且相容的先序、中序能通过“定位根、划分左右、递归恢复”唯一确定二叉树。恢复题既训练算法，也检验学生是否真正理解子树、位置和访问语义。

主要认知跨越为 OPS、ALG、COR：从知道结构转向设计访问顺序，并解释不重不漏的成立理由。INF、INV、COST 支撑本讲，不另铺开新理论。依据为课程认知主线 v0.2、D001–D020 Matrix v0.1 的 D009 条目及 WhyOS 课程理解 Memo v0.3；这些都是设计依据，不能替代学生学习证据。

## 主要问题与案例

问题链：表达式需要什么先就绪 → 访问究竟是什么 → 根应何时访问 → 返回后谁记得继续做什么 → 怎样不重不漏 → 栈和队列怎样改变顺序 → 一行记录丢失了什么 → 两种序列何时能恢复结构。

1. **D008 表达式** `(a-b)*(c+d)`：先序 `*-ab+cd`，中序 `a-b*c+d`（直接输出会丢失原结合关系），后序 `ab-cd+*`。完全括号化为 `((a-b)*(c+d))`。
2. **主推演树**：A 左 B、右 C；B 仅右 D；C 仅左 E。刻意采用非对称单孩子结构，避免把层序误当先序或忽略空位置。
3. **信息不足反例**：A 仅左 B 与 A 仅右 B，先序均 AB、后序均 BA。
4. **不相容反例**：先序 ABC、中序 CAB。根 A 的左子树应含 C，但先序切出的左子树根是 B。
5. **独立恢复**：先序 PQSRT、中序 SQPRT。P 左 Q、右 R；Q 仅左 S；R 仅右 T。后序 SQTRP，层序 PQRST。

### 实现与结论边界

- 输入指针必须表示有限合法树，遍历不检测任意指针图中的环或共享。非递归实现的存在也不表示能处理无限或非法输入。
- 固定容量 `CAP=32`，每个结点使用单字节标识。遍历输出不足时返回失败，输出中可能保留前缀；调用者必须检查返回值。
- 恢复函数要求 NUL 结尾字符串、互异标识和相容的分割；失败清空根与已用计数，不返回半棵树。结点存放在调用者的 `Tree` 池中，不可在构造后按值复制该结构，也不可返回已失效的局部池。
- 遍历的 Θ(n) 时间以单次访问 O(1) 为前提。递归/栈的 O(h) 和队列的 O(w) 是活跃辅助状态上界，不包括输出、输入树与本演示预分配容量。
- 恢复采用分段线性找根，最坏 O(n²) 时间、O(h) 递归辅助空间，另需保存 n 个输出结点。本讲不加入索引优化来转移教学重点。
