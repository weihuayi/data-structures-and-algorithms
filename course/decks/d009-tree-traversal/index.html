操作语义

什么叫遍历？什么叫访问？

教材定义（概述）
遍历：按确定规则，使每个结点被访问一次且仅一次。

visit(p) 可执行输出、计数、判断、修改数据或局部计算。

进入：开始处理子树。
访问：执行指定操作，本例输出标识。
返回：继续未完成的调用，不自动输出。

图中 A 已访问，但它的子树尚未完成。

教学注记

进入 ≠ 访问 ≠ 返回。前提为有限合法二叉树，无环、无共享结点；访问操作会结束，且不破坏遍历所依赖的链接。定义是概述，不冒充教材逐字原文。

教学注记

这些记录来自后面将建立的四种规则。此处不要求学生提前知道术语，也不把任意排列当作某种已定义遍历的结果。

N / L / R

遍历一棵非空二叉树，有哪三件事？

N：访问根 A。

L：遍历以 B 为根的整棵左子树。

R：遍历以 C 为根的整棵右子树。

L ≠ 左孩子；R ≠ 右孩子。
处理 L 要覆盖 B、D，处理 R 要覆盖 C、E。

访问时机

先、中、后，说的是谁的先、中、后？

名称访问次序
先序N L R
中序L N R
后序L R N

说的是根 N 相对于左右子树的访问时机。

固定左子树先于右子树；
每棵子树重复同一规则，空树直接返回。

递归骨架

三个名字，为什么只需要一副递归骨架？

void traverse(const Node *p)
{
    if (p == NULL) return;
    /* position 1 */
    traverse(p->left);
    /* position 2 */
    traverse(p->right);
    /* position 3 */
}

选择一个位置插入 visit(p);：

位置得到的遍历
1先序 NLR
2中序 LNR
3后序 LRN

递归结构相同，根的访问时机不同。

教学注记

这是一份待填的骨架，不是已完成的输出程序。三处只选一处。课堂程序 depth_first 用 order 选择 PRE、IN、POST，并额外检查输出容量与失败返回。

正确性

为什么不会重复、不会遗漏，而且一定结束？

任务应用

同一棵表达式树，为什么需要不同顺序？

遍历 / 写法运算符位置与例子整棵树输出
先序 / 前缀在前：− a b× − a b + c d
中序 / 中缀居中：a − ba − b × c + d
后序 / 后缀在后：a b −a b − c d + ×

“前、中、后缀”说的是运算符相对操作数的位置。
操作数也可以是整个子表达式。

中序需用括号保留结合关系：\(((a-b)\times(c+d))\)。

求乘法结果前，先求左右子表达式。

教学注记

表中三种单次减法都表示 a 减 b，操作数次序不变。前缀先读运算符，再读它的两个操作数；后缀先给出两个操作数，再给出运算符。本例每个运算符都是二元的，所以前缀、后缀序列可以保留结合结构，不依赖括号；若运算符元数不明确，不能直接套用此结论。前缀中 × 后的两个操作数分别是 − a b 和 + c d；后缀中最后的 × 使用 a b − 与 c d + 的结果。括号是在进入、离开时附加的输出，不是重复访问结点。求值需使用子树结果，不等同于打印后序序列。

代价

一次遍历需要多少代价？

完整遍历时间活跃辅助空间
递归三序\(\Theta(n)\)\(O(h)\) 调用栈
层序\(\Theta(n)\)\(O(w)\) 队列

前提：每个结点执行一次 \(O(1)\) 局部工作。

\(n\) 为结点数；\(h\) 为层数；\(w\) 为最大层宽。
本树 \(n=5,h=3,w=2\)。

空间来自同时保存的尚未完成状态。

教学注记

按非空树讨论渐近上界；空树只有常数开销。队列可能混合相邻两层，占用不一定恰等于 w，但至多 O(w)。输出若另存需 O(n)，不计入这里的辅助空间；演示预分配 CAP 不等于活跃状态。恢复采用分段线性找根，最坏 O(n²)，不套用本页遍历代价。
