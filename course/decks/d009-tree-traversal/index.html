回到问题

同一棵表达式树，为什么需要不同顺序？

       ×
     /   \
    −     +
   / \   / \
  a   b c   d

回到 D008 的 (a−b)×(c+d)。
写出算式时，运算符放在哪里？计算乘法时，又必须先知道什么？

教学注记

表达式只使用二元运算符。运算符的位置涉及输出形式，执行运算则依赖子表达式结果。让学生先说出“根要等两个子树的结果”，再引入后序术语。

操作语义

“访问一次”究竟做什么？

教材定义（概述）
遍历二叉树：按某条搜索路径巡访树中结点，使每个结点被访问一次且仅一次。

访问可以是输出标识、更新计数，或利用子树结果完成计算。

本讲先约定：visit(p) 输出 p 的标识。
经过结点、返回结点，都不自动算一次输出。

教学注记

对应 5.5.1，依据仓库教材接口记录概述，不作逐字引文。遍历输入为有限合法二叉树，无环、无共享结点。数据值可重复，但手工序列和恢复题使用互异标识。

算法设计

一棵非空树里，有哪三件事要做？

N：访问根
L：遍历左子树
R：遍历右子树

约定左子树先于右子树：
根放在前、中、后，分别得到 NLR、LNR、LRN。

每棵子树都使用同一条规则；空树直接返回。

教学注记

L 和 R 表示完成整棵子树，不能误读成只访问左、右孩子。左右对调也可定义遍历，但本课先序、中序、后序默认左先于右。

手工推演

先看完整先序，再补全中序

       A
     /   \
    B     C
     \   /
      D E

先序示例：A → B → D → C → E。

中序补全：B 的左侧为空，先输出 B；完成 D 后，返回 A，输出 ____；C 子树应输出 ____。

教学注记

先序完整过程在下一页。中序两空为 A、E C，完整 B D A E C。要求解释返回后为何此时访问 A，不能只按图中位置猜顺序。此页是支架练习，不计作独立三序证据。

调用与返回

先序为什么在 D 之后回到 C？

事件已输出尚未完成的任务
进入 A，访问 AA完成 B 子树，再完成 C 子树
进入 B，访问 BA BB 的右子树 D；之后 C 子树
完成 D，返回 B，再返回 AA B DC 子树
访问 C，再完成 EA B D C E无

从 D 到 C 没有一条孩子边。程序靠“返回后继续做什么”接上工作。

教学注记

空调用省略。回收 D006：栈帧保存当前结点及执行位置，返回并非重新访问。请学生解释为什么 A 不会再输出一次。

C 程序

换的是递归结构，还是访问时机？

void inorder(const Node *p) {
    if (p == NULL) return;
    inorder(p->left);
    visit(p);
    inorder(p->right);
}

先序在递归前访问；后序在两次递归后访问。
现在独立写主例后序，并解释 A 为什么最后输出。

教学注记

独立后序 D B E C A；若学生先写 A，回到“子树完成后才访问根”。各递归函数调用自身；不是在先序函数内调用 inorder。演示代码将三种访问时机合并为 order 参数，以便同一输入核对。此处展示单独的中序教学模板。

正确性

为什么这样不会重复，也不会漏？

  • 空树：没有结点要访问，直接结束。
  • 非空树：根、左子树、右子树互不重叠，合起来恰好是整棵树。
  • 若两棵更小的子树各被正确遍历一次，再访问根一次，就覆盖整棵树且不重复。

递归每次进入更小的子树，最终到达空树。

教学注记

这是按树结构归纳的理由。必须依赖 D008 的无环、子树不共享结点等条件。共享同一孩子指针会重复访问，成环可能不终止。此处不引入图的 visited 修补，留给 D012。

回到案例

表达式树的三种输出有什么用途？

顺序输出需要补充什么
先序× − a b + c d已知每个运算符的元数
中序a − b × c + d括号才能保留原来的结合关系
后序a b − c d + ×对子表达式先求值，再执行根运算

先判断：计算根运算前需要什么结果？选择顺序并说明依赖。直接中序输出，不能保证保留原算式。
完全括号化输出为 ((a−b)×(c+d))。

教学注记

括号输出是在进入、离开运算符子树时附加的动作，并非多访问一次结点。后缀求值回收 D005：遇操作数入栈，遇运算符先弹右操作数、再弹左操作数。

显式栈

不靠系统调用栈，待做的任务放在哪里？

根入栈
只要栈不空：
    弹出 p，访问 p
    若右孩子存在，右孩子入栈
    若左孩子存在，左孩子入栈

回收 D005：后进先出。要先处理左子树，就先压右、再压左。

这是先序的显式栈实现。中序、后序还需安排不同的访问时机。

栈的推演

栈里的 C 为什么要等一等？

弹出并访问入栈操作栈底 → 栈顶（初始 A）
A先压 C，再压 BC B
B压 DC D
D无C
C压 EE
E无空

栈里存放待处理子树的根；最上面的任务下一步执行。

教学注记

不变量：栈中各待处理子树互不相交，与已访问结点一起覆盖原树；弹出根后以其非空子树替换任务。任务顺序决定输出。若改成先压左再压右，得到 A C E B D，即根—右—左顺序。

层序

要先处理所有浅层结点，该换什么纪律？

若要按层展示结构，就不能在 B 下面一直深入。

根入队
只要队列不空：
    出队 p，访问 p
    非空左孩子入队
    非空右孩子入队

先发现的先处理：回收 D005 的 FIFO 队列。

教学注记

这里固定每层从左到右。层序也称广度优先遍历，先序/中序/后序属于深度优先遍历方式。不要将深度优先仅等同于先序。

队列的推演

队列怎样保证浅层在前？

出队并访问队头 → 队尾（初始 A）输出
AB CA
BC DA B
CD EA B C
DEA B C D
E空A B C D E

新孩子进入队尾，排在当前尚未处理的结点后面。

教学注记

队列保存已发现而未访问的结点，按层次非递减排列；同层保持父结点处理顺序及左先右后的次序。合法树中每个非根结点只有一个父结点，所以恰入队一次。队列可同时包含相邻两层，不能说永远只存一层。

机制收口

栈和队列改变了哪些东西？

机制下一项工作主例输出
递归先序 / 显式栈先完成最近待处理的子树A B D C E
层序队列先处理最早发现的结点A B C D E

结点和链接没有改变，待处理工作的组织方式改变了顺序。

中序、后序还要明确“何时访问根”，不能只把栈替换成队列。

代价

每个结点只访问一次，代价就一样吗？

方法时间：visit 为 O(1)辅助空间，不计输出
递归三种深度优先Θ(n)O(h) 调用栈
显式栈先序Θ(n)O(h) 待处理根
层序队列Θ(n)O(w) 活跃队列

h 为高度，w 为最大层宽。单链可能 h=n，宽树可能 w 与 n 同阶。

演示为小树预留固定容量数组；实际分配容量与活跃元素数要区分。

教学注记

对非空合法树讨论，空树为常数工作。递归还会遇到空孩子，但总工作仍是线性。队列至多混合相邻两层，因此是 O(w)，不一定恰好等于 w。显式先序栈在单链上可以只有 1 项，O(h) 是上界。记录完整输出还需 O(n) 空间。

操作迁移

“访问”换成统计，可以解决什么？

size_t leaves(const Node *p) {
    if (p == NULL) return 0;
    if (!p->left && !p->right) return 1;
    return leaves(p->left) + leaves(p->right);
}

D008 的叶子统计现在有了理由：
空树给 0，叶子给 1，其余结点汇总两棵子树的结果。

教学注记

本例 2 个叶子：D、E。不要将空孩子计为叶子，不能写成“左或右为空就返回 1”。这是后序式结果汇总，不要求显式打印结点。复杂度 Θ(n)，递归辅助空间 O(h)。

信息与恢复

只有一行访问记录，能画回原树吗？

先序都是 A B：
     A           A
    /             \
   B               B

普通先序序列没有记下哪个孩子位置为空。
这两棵树的后序也同为 B A。

所以先序加后序，通常仍不能唯一确定二叉树。

教学注记

前提是普通序列，不含空标记。若先序显式记录所有空子树标记，信息量已经变化，可以唯一恢复。不要无条件说任何两种遍历都能恢复。

恢复机制

先序加中序，多提供了什么信息？

先序：A | B D | C E
中序：B D | A | E C

先序首项确定根 A。
中序中 A 的位置，把结点分成左子树 B D 与右子树 E C。

左子树有 2 个结点，因此先序接下来的 2 项属于左子树。

教学注记

先停在第一刀，让学生自己继续。子序列必须按各自的位置切分，不能把中序左右片段直接当作子树先序。

恢复推演

对子树重复切分，怎样得到原来的链接？

子问题先序中序根及分割
整棵树A B D C EB D A E C根 A：左 B D，右 E C
左子树B DB D根 B：左空，右 D
右子树C EE C根 C：左 E，右空

每次找到根，再切出两棵更小的子树；空片段结束。

教学注记

最后画出第 5 页的树，重新生成两种遍历核对。程序采用分段查找根的直接实现，最坏 O(n²)，不把它误称为线性恢复。课堂不要求编写恢复代码。

条件与正确性

怎样保证恢复唯一？什么输入必须拒绝？

  • 结点标识互异，才能在中序中唯一定位根。
  • 长度相等、标识集合一致，是必要条件。
  • 每轮切分也必须一致，不能只检查总集合。
先序 A B C，中序 C A B
根 A 的左子树应是 C，先序的下一个却是 B

这组序列虽然标识集合相同，仍无法组成同一棵树。

教学注记

互异且相容的先序与中序唯一确定二叉树：根唯一、左右集合唯一，递归套用同一理由。后序加中序也可，用后序末项找根。重复数据值可使用互异结点 ID，不能静默取第一次匹配。

不看示范，能恢复另一棵树吗？

线索化引导

若经常找中序的下一位，能多存一点信息吗？

中序序列 B D A E C 中，D 的下一位是 A。
原来的孩子指针未必直接指向这个后继。

线索化：利用原本为空的指针域，记录指定遍历次序下的前驱或后继，并用标志区分孩子与线索。

教材 5.5.2：认识目的、标志位与中序前驱/后继。构造和遍历细节课后阅读。

教学注记

线索不都指向父结点，具体含义取决于遍历次序。把线索误当孩子递归，可能成环。新增辅助信息改变后继访问能力，也增加维护约束，回收 D008 的表示选择。考试范围按课程正式通知，本页不自行豁免。
