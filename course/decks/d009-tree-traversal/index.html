操作语义

进入、访问、返回，是同一件事吗？

进入：开始处理这棵子树。

访问：执行 visit(p)，本例输出标识。

返回：回到尚未完成的调用；不自动输出。

先序刚访问 A：已输出 A，
但 A 的两棵子树还没有完成。

教材定义与条件（概述）
教材定义（概述）
遍历使每个结点被访问一次且仅一次。

前提为有限合法二叉树，无环、无共享结点。本讲先固定访问为输出标识。

算法设计

一棵非空树里，有哪三件事要做？

N：访问根 A。

L：遍历以 B 为根的整棵子树。
R：遍历以 C 为根的整棵子树。

固定左先于右：
先序 NLR；中序 LNR；后序 LRN。

每棵子树重复同一规则；空树返回。

void inorder(const Node *p) {
    if (p == NULL) return;
    inorder(p->left);
    visit(p);
    inorder(p->right);
}

先中序补全，再后序独立留痕。各递归函数调用自身；程序以 order 参数合并访问时机。

正确性

为什么不会重复，也不会漏？

根、左子树、右子树互不重叠，合起来就是整棵树。

两棵更小的子树各正确遍历一次，再访问根一次，就不重不漏。

递归进入更小子树，最终到空树并返回。

教学注记

按结构归纳。共享孩子会重复访问，环可能导致不终止；合法树条件不可省略。这里不增加图的 visited 标记，留到 D012。

先序× − a b + c d
中序a − b × c + d
后序a b − c d + ×

直接中序输出丢失原结合关系。
补全括号：\(((a-b)\times(c+d))\)。

求乘法结果前，先算两个子表达式。

教学注记

表中是输出标记序列，不是把后缀写作代数乘法。前缀、后缀的解释依赖运算符元数；括号是在进入、离开时附加的输出，不是重复访问结点。后缀求值先弹右操作数，再弹左操作数。

显式栈

不用调用栈，待做的任务放在哪里？

根入栈
只要栈不空：
    弹出 p，访问 p
    非空右孩子入栈
    非空左孩子入栈

栈中只存待处理子树的根。
后进先出：要先处理左边，就先压右边。

教学注记

此显式栈不保存递归程序的返回位置，不能与调用帧混为一谈。这里只实现先序，中序、后序需要安排不同访问时机。

代价

访问次数相同，辅助空间也相同吗？

方式时间（单次访问常数代价）活跃辅助空间
递归三序\(\Theta(n)\)\(O(h)\) 调用栈
显式栈先序\(\Theta(n)\)\(O(h)\) 待处理根
层序\(\Theta(n)\)\(O(w)\) 队列
教学注记

\(h\) 为层数，\(w\) 为最大层宽。显式先序栈在单链上可只有一项，\(O(h)\) 是上界；队列会混合相邻两层，容量不一定恰等于 \(w\)。输出另需 \(O(n)\) 空间，演示预分配 CAP 不等于活跃状态。

操作迁移

叶子数怎样从子树汇总回来？

空树返回 0；叶子返回 1。

B：\(0+1=1\)，C：\(1+0=1\)。
A 汇总：\(1+1=2\)。

if (!p) return 0;
if (!p->left && !p->right) return 1;
return leaves(p->left)
     + leaves(p->right);
教学注记

这是后序式结果汇总，不只是把打印换成计数。B、C 虽然各有一个空孩子，却不是叶子。复杂度 \(\Theta(n)\)，递归辅助空间 \(O(h)\)。
