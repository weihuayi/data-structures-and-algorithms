# D002｜数据组织如何改变搜索

## 本质关系

数据的组织方式改变搜索可利用的信息：无序时一次比较只能排除一对候选；有序以后，不等式方向使一次比较能排除一批（排除依据可写成不等式证明）。双索引扫描的移动规则由"不遗漏"不变量保证（L<R 且每步排除的一侧确无解）。代价可计算、可对照：枚举 O(n²) vs 排序＋扫描，预处理的代价能否摊还取决于查询是否反复。任务变化先于方法变化——需求一改，先检查保留的信息与停止条件。

## 主要问题

- 为什么有序以后可以一次排除一批候选？
- 双索引扫描的移动规则为什么不会漏解？
- 数据元素、数据项、逻辑结构与存储结构分别在描述什么？
- ADT 怎样规定基本操作，数组怎样支持这些操作？
- 算法的定义、五个特性与评价标准怎样对应案例？
- 比较算法代价时，哪些时间与空间成本必须计入？
