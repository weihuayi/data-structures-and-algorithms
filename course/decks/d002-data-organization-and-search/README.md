# D002｜数据组织如何改变搜索

## 主要教学目标

从商品配对的枚举继续追问，认识数据的组织关系怎样改变算法可利用的信息与候选排除方式，再由具体案例自然进入数据元素、数据项、逻辑结构、存储结构、数据结构与算法等专业术语。

## 主要问题

- 为什么有序以后可以一次排除一批候选？
- 双索引扫描的移动规则为什么不会漏解？
- 数据元素、数据项、逻辑结构与存储结构分别在描述什么？
- 比较算法代价时，哪些工作必须计入？

## 主要案例

有序商品配对与双索引扫描。
