关键规则：发现即标记

看到邻居，为什么不能立即再走一次？

若 v 尚未发现：
    seen[v] = true
    parent[v] = u
    输出 v，并安排它的后续工作
否则：跳过这次重复发现
本讲不变量：每个顶点至多被安排一次；seen 一旦为真不再变回假；parent 只在首次发现时写入。

第一次发现时登记，后面不同路径到达同一顶点时复用这一信息。

教学注记

visited 常译为已访问；本讲 seen 精确定义为已发现。B 再看到 A 时跳过；A 后来看 C 时可能已被 DFS 发现。标记不能只在全部邻居处理后才做。

深度优先

先把一条分支探索完：DFS

dfs(u):                     # u 已发现
    对每个邻居 v：
        若 v 未发现：
            发现 v：seen[v]=true；parent[v]=u；输出 v
            dfs(v)
教材定义（概述）：DFS 沿未发现邻居深入，无可继续时回溯。
教学注记

教材定义（概述）：深度优先搜索从起点出发，沿未访问邻接点深入，无可继续时回溯。回收 D006/D009：调用栈记住当前顶点和继续扫描的位置。根与子结点都由 discover 在调用前发现；本页把发现动作写在父结点一侧，语义与“进入即发现”一致。

完整示例

从 C 返回后，A 还要输出一次吗？

动作发现序列栈（底→顶）
发现 A，沿 AB 深入A BA B
B 跳过 A，发现 CA B CA B C
C 跳过 A/B，发现 DA B C DA B C D
D 无邻居，返回 CA B C DA B C
C、B、A 返回；A 看 C 已见A B C D空

树边：AB、BC、CD；AC 不是树边。

教学注记

沿编号升序扫描；D→C→B→A 依次返回，A 再看 C 时 seen[C] 已为真，返回不等于再次输出。边数与访问次数不同，已见邻接项仍会被检查。E 不在本次搜索树内。

显式栈

不用递归，栈里要记住什么？

Frame {vertex, next}
初始：发现 A，压 (A,0)
循环：
  看栈顶 f，取下一个邻居 v
  无剩余邻居：出栈
  v 已发现：继续
  v 未发现：发现 v，输出，压 (v,0)
栈（动作后）动作输出
A:0初始：发现 A，压栈A
A:1 B:0A 看 B：发现 BA B
A:1 B:1 C:0B 看 C：发现 CA B C
A:1 B:1 C:1 D:0C 看 D：发现 DA B C D
A:1 B:1 C:1D 无邻居，弹出 DA B C D
A:1 → 空C、B、A 依次返回A B C D

保留“返回后从哪里继续”，可复现递归 DFS 的顺序和树边。

教学注记

根先发现并压栈。区别于一次把全部邻居压栈：后者需要单独说明入栈顺序和标记时机，不能无条件声称与递归树完全相同。表中栈列底→顶，A:1 表示 A 的下一个邻接项下标为 1；输出发生在发现时。此帧式写法直接支撑正式算法题 (2)。完整 C 实现在 code/traversal_demo.c 的 dfs_stack。

广度优先

先处理已经发现的近邻：BFS

发现起点 s，令 distance[s]=0，s 入队
只要队列不空：
    u 出队
    对每个尚未发现的邻居 v：
        标记 v；parent[v]=u
        distance[v]=distance[u]+1；v 入队
教材定义（概述）：BFS 从起点的邻居开始，逐层向外扩展。
教学注记

教材定义（概述）：广度优先搜索先访问起点的邻接点，再逐层向外扩展。回收 D005 FIFO；输出在发现时，队列存已发现、尚未完成邻接扫描的顶点。

队列推演

B 看见 C 时，C 还在队列里

刚完成的动作队头→队尾首次发现序列
发现 AAA
处理 A，发现 B、CB CA B C
处理 B，C 已标记CA B C
处理 C，发现 DDA B C D
处理 D空A B C D

parent[B]=A，parent[C]=A，parent[D]=C。
distance：A=0，B=1，C=1，D=2；E 未到达。

教学注记

刻意使用 DFS/BFS 发现序列相同的主例：两者的搜索树和深度不同。队列中顶点都已标记；不能仅凭打印序列判断算法机制。

反例与边界

等出队才标记，会怎样？

A 已把 B、C 入队；若 C 还未标记，处理 B 时又会把 C 入队。

正确位置：发现 v → 标记 v → 入队 v
错误预测：队列可能出现 C、C

标记前移，使每个顶点至多入队一次。

教学注记

让学生先预测重复项。晚标记并在出队时过滤的另一种算法可能仍得到可达集合，但会重复入队，不能沿用本实现的容量与一次入队论证。此处不把所有晚标记算法都判作不正确。

正确性

为什么不重复、不遗漏，而且会结束？

  • 不重复：第 8 页不变量——首次发现即标记；只安排未发现顶点。
  • 不遗漏：若某可达点漏掉，沿源到它的路径找第一个漏点；其前驱被处理时本应发现它。
  • 终止：顶点有限，每个顶点只安排一次，邻接枚举也有限。
教学注记

假设图在搜索中不变，邻接枚举完整且终止。全图无遗漏还需外层扫描。这里只用任务相关的正确性语言，不新增统一证明框架的背诵要求。

代价推导

遍历的代价来自哪些扫描？

完整遍历 n 个顶点枚举总工作时间
邻接矩阵每个顶点扫描 n 个位置Θ(n²)
邻接表n 个表头及全部邻接项Θ(n+m)

空间：seen、parent、distance 与栈/队列均为 O(n)；不计图与输出。

m 为边数（教材记 e）；无向图有 2m 个邻接项，有向图有 m 个。

教学注记

visit 假定 O(1)。单源只到达 r 个顶点时：矩阵扫描 rn 格，表扫描可达顶点的出邻接项；本程序初始化 n 个状态另需 O(n)。主例单源矩阵 20 格、表 8 项；全图矩阵 25 格、表仍 8 项。构建邻接表在本演示从矩阵扫描生成，另为 O(n²)，不能算成搜索本身。

适用条件

队列层次能回答哪一种距离？

主例 BFS：A=0，B=1，C=1，D=2，E=-1。
主例 DFS 树深度：A=0，B=1，C=2，D=3。

BFS 按距离非递减处理顶点，首次发现即给出最少边数。
若道路耗时不同，最少边数不保证耗时最少。

教学注记

按层归纳：处理距离 k 的顶点时，新发现邻居给出 k+1；若它有更短路径，其前驱应更早处理并发现它，与首次发现矛盾。反例：直达 AD 耗时 10，A→C→D 各 1，则一条边反而更慢。BFS 距离结论适用于无权或每边等代价；D014 处理带权最短路径。E 的 -1 为未到达哨兵，不是负距离。

方向与边界

搜索森林的树数，就是强连通分量数吗？

从 A 出发：只发现 A，得到一棵树 {A}。

从 B 出发：一次发现 B、A，得到一棵树 {B,A}；这棵树包含两个强连通分量 {B}、{A}。

树数取决于起点和扫描次序，不能当作 SCC 数；SCC 算法不在本讲展开。

教学注记

例中强连通分量始终是 {A}、{B}；从 B 得到一棵树已反驳“树数=SCC数”。弱连通分量始终为 1。若按 A、B 扫描，会得到两棵树，这更说明树数依赖起点与次序。
