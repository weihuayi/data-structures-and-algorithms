第二节 · 深度优先搜索

看到邻居，为什么不能立即再走一次？

若 v 尚未访问：
    visited[v] = true
    parent[v] = u
    输出 v，并安排它的后续工作
否则：跳过这次重复到达
本讲不变量：每个顶点至多被安排一次；visited 一旦为真不再变回假；parent 只在首次访问时写入。visited[v]=true 只表示首次访问已发生，不代表 v 的邻接点已处理完。
教学注记

本讲与教材一致使用 visited（已访问），标记时机为首次访问时，不等到邻居处理完。B 再看到 A 时跳过；A 后来看 C 时，C 可能已被深度优先搜索访问过。

第二节 · 深度优先搜索

先把一条分支探索完：DFS

dfs(u):                     # u 已访问
    对每个邻居 v（按编号升序）：
        若 v 未访问：
            访问 v：
                visited[v]=true；parent[v]=u
                输出 v
            dfs(v)
教材定义（概述）：深度优先搜索（Depth First Search，DFS）：沿未访问邻接点深入，无法继续时回溯。
教学注记

根由外层先访问；返回后继续检查当前顶点的下一个邻接项。教材 6.5.1 算法 6.3 在进入 DFS(v) 时置 visited[v]=true 并输出；本页把访问动作写在父结点一侧（调用 dfs(v) 之前完成），中间无其他操作，语义一致。

第二节 · 深度优先搜索

把邻居编号降序后，DFS 会先走谁？

编号：A=0、B=1、C=2、D=3、E=4。

顶点升序（编号小→大）降序（编号大→小）
A(0)B(1)、C(2)C(2)、B(1)
C(2)A(0)、B(1)、D(3)D(3)、B(1)、A(0)

DFS 已访问 A、C；下一位 ______，再下一位 ______。

核对答案与理由

答案：A C D B；下一位 D，再下一位 B。

理由：C 的降序邻接 D、B、A；A 已访问，先 D；D 只连 C，返回 C 后 B；B 的邻居 A、C 都已访问。树边 AC、CD、CB，集合仍为 A B C D。

降序：按整数编号从大到小，不是字母序/几何位置；边存在性不变。

教学注记

2 分钟补全；先让学生写 D、B，再展开核对。不要先投影答案。

第三节 · 广度优先搜索

为什么不重复、不遗漏，而且会结束？

  • 不重复：首次访问即标记；只安排未访问顶点。
  • 不遗漏：若某可达点漏掉，沿源到它的路径找第一个漏点；其前驱被处理时本应访问它。
  • 终止：顶点有限，每个顶点只安排一次，邻接枚举也有限。

第四节 · 性质、代价与应用

搜索森林的树数，就是强连通分量数吗？

全图遍历只初始化一次 visited；不同根之间不重置。

顺序实际过程 → 搜索森林
A,B访问 A；再以 B 为根，B→A 发现 A 已访问 → {A}、{B}（2 棵）
B,A从 B 访问 B、A；外层扫描 A 时跳过 → {B,A}（1 棵）

两种情况都访问 A、B 各一次；森林的不同树互不共享顶点。

强连通分量（Strongly Connected Component，SCC）是任意两顶点互相可达的极大子图。两种顺序下 SCC 都是 {A}、{B}；{B,A} 一树含两个 SCC；树数随外层顺序变化，不能当作 SCC 数。

理由：BFS 逐层，首次访问 T 时距离已最少；U 无入边。

教学注记

保留 7 分钟独立作答、2 分钟反馈。最低证据：有向图；稀疏邻接表可枚举；FIFO 与首次访问即标记；PQ R S T 或 PR Q S T，T=3、U 不可达；S 的父可变，距离不变。若选 DFS 求可达可以，但不能用首次访问的树深度保证最少点击。若 7 分钟内多数学生只完成前两问，第 3 问改为口头追问或课后小题，保留建模与 BFS 轨迹；记录实际用时。

十字链表：同一条弧为什么能从两个入口找到？

弧结点tailvexheadvexhlink（同头）tlink（同尾）
a1PQ—a2
a2PR——
a3QSa4—
a4RS——

firstout：P a1→a2；Q a3；R a4；S 空。
firstin：P 空；Q a1；R a2；S a3→a4。

a3（Q→S）既在 Q 的 firstout 链上，也在 S 的 firstin 链上；同一条弧，两个入口。

教学注记

十字链表把邻接表与逆邻接表结合：每条弧一个结点，同时挂在“同尾”和“同头”两条链上。教材 6.4.3：弧结点 tailvex/headvex 是弧尾/弧头位置，hlink 指向弧头相同的下一条弧，tlink 指向弧尾相同的下一条弧；顶点结点 firstin/firstout 分别指向第一条入弧/出弧。本页不展开建表与增删代码。

补充 · 扩展存储

邻接多重表：一条无向边只存一份记录

普通无向邻接表把一条边存两份；邻接多重表每条边只建一个结点，同时挂在两个端点的链上。

边结点markivexjvexilinkjlink
e1unvisitedABe2e3
e2unvisitedAC—e3
e3unvisitedBC——

firstedge：A e1→e2；B e1→e3；C e2→e3。
e1（A—B）经 ilink 进 A 的边链、经 jlink 进 B 的边链；同一个边结点被两个端点共享。

mark 标记“这条边是否被搜索/处理过”，不是顶点访问标志 visited[v]。

教学注记

教材 6.4.4：边结点 mark 是边标志域，ivex/jvex 是两端点位置，ilink/jlink 分别指向依附两个端点的下一条边；顶点结点 firstedge 指向第一条依附边。邻接多重表与邻接表存储量同阶，但每条边只有一个结点。
