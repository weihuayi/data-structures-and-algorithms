# D012｜图的遍历：怎样组织待处理工作

## 设计卡：本质关系

图保存原始邻接关系，搜索另行维护已发现信息和待处理工作。DFS 借助调用栈或显式帧栈保存“深入之后从哪里继续”；BFS 借助 FIFO 队列按最少边数逐层扩展。seen 防止重复安排，parent 记录第一次发现的来源。输出顺序由起点、邻接次序与策略共同决定，不能简化为“存储结构决定唯一序列”。

主要认知跨越为 OPS、REP、ALG、COR：从树上默认单一到达路径的遍历，转向一般关系中以辅助信息和工作纪律组织搜索。回收表示—能力—代价—选择，以及预测—运行—检查。不变量与信息利用作为具体解释工具，不要求学生背诵额外框架。

设计依据：课程认知主线 v0.2、D001–D020 Matrix v0.1 的 D012 与 Checkpoint C；WhyOS `courses/why_data_structures_and_algorithms_structured_understanding_memo.md` 和 `why_course_engineering_structured_understanding_memo.md` v0.3。备忘录的形式化语言经过任务化转换，不直接转写为学生要求。资产与软件验证不代表已观察到学习达成。

## 实现与验证边界

- 演示仅支持 1–16 个顶点的有限、无权、简单图；拒绝空顶点集、超容量、越界、自环与重复边。无向输入的反向重复同样拒绝，有向互反弧合法。算法思想可扩展，但本演示不声称支持所有图类型。
- 邻接表以邻居数组实现，按编号升序构造，降序模式反向扫描。矩阵与表同时保留是为了对照，不是低内存部署方案。构造时 O(n²) 扫描另计，单次搜索不重建表示。
- `search` 接受成功构造且搜索中不修改的图。非法起点/枚举参数失败并清空结果；内部指针要求非空。输出最多 CAP 个顶点，发现即标记保证帧栈和队列不超容量。
- `distance` 在 DFS 中只是树深度；BFS 单源时才是从该源的最少边数。全图模式每棵树从 0 重启。parent=-1 可为根或未发现，结合 seen 判断。
- 递归 DFS 与帧式 DFS 在相同枚举次序下逐项等价；不把这一结论推广到所有“顶点入栈”写法。
- 内置断言检查单顶点、单链满容量、非法构图、有向双向弧及非法起点。不要定义 NDEBUG 后声称断言已经执行。
