## 事实基线与原因

来自教师 2026-11-16 上传的 D018 本地第 1、2、9、12 页截图，以及当前 main 的 D017/D018 页面和 CSS：

- 标题使用公共 Deck 大字号，D018 的普通 div、span、SVG 标签却多采用继承字号与 0.57em、0.79em，导致关键标签偏小；D017 明确设置正文、任务与结构图的投影字号。
- D018 的 hash-lesson 对全部内容使用 max-width:1120px 和自动居中，而主标题位于更宽的 slide-inner，形成水平对齐错位。
- 原桶链 SVG 使用 910×295 画布、13–20 的 SVG 内部文字，并进一步受 720p 最大高度限制；没有溢出不等于关键关系可读。
- 第 2 页大纲相对清楚，可作为正面对照，本轮不改动。
