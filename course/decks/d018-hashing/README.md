## 一、教学中心与认识边界

**中心问题**：不依赖关键字的大小顺序，怎样通过计算映射快速定位记录，并在发生冲突和动态更新时保证查找正确？

主要认知跨越：从“利用顺序、比较并缩小候选范围”转向“由关键字计算候选地址、维护冲突处理规则，再有条件地评价代价与结构选择”。**散列地址是候选位置，不等于已找到记录；期望常数成本不是每次操作的无条件保证。**

本讲主例用非负、互异整数关键字描述动态字典（按键精确查找、插入、删除）。保留四项教学目标：

| 目标 | 学生侧必须观察的行为 |
| --- | --- |
| G1 映射定位 | 区分关键字与槽位下标，计算地址、识别冲突并说明不同关键字为何可能同址 |
| G2 正确性机制（重心） | 独立构造链地址与线性探查表；解释命中、EMPTY 失败停止、DELETED 继续探查以及删除后的路径保持 |
| G3 计算代价 | 从轨迹统计探查次数，在给定概率前提下求成功／失败 ASL；辨认冲突分布、装载因子与成本模型 |
| G4 条件化选择 | 比较散列与 AVL 在精确查找、范围查询、动态维护及最坏保证下的适用性 |

**不默认课堂完整展开**：通用散列家族证明、二次探查与双重散列的完整覆盖性证明、重建摊还严格证明、生产级扩缩容与并发安全。这些属于教师专业支撑或延伸。**不能忽略**：教材二次探查的计算训练；探查规则与数组容量的区分。

## 二、先修接口与数学约定

- D003：数组按下标 O(1) 访问不等于按关键字 O(1) 查找；D004 链表为桶内节点提供表示。
- D016：查找成功／失败、关键字比较或检查次数、ASL 要给计数口径与查询概率；D017：AVL 依靠顺序和平衡不变量得到最坏 O(log n) 的路径界。
- 散列表数组容量为 `m`，初始地址 `h(k)\in[0,m-1]`，**不要求** `h` 取遍全部下标；探查序列 `p(k,i)=(h(k)+i)%m`。主例 `m=7`、`h(k)=k%7`，仅考虑非负整数关键字。
- 链地址法中 `m` 表示桶数组长度，桶内可保存多条记录，`alpha=n/m` 是平均每桶记录数；开放定址法中 `m` 表示可存放记录的槽位数，`alpha=n/m` 是有效槽位占比，尚有墓碑可能影响探查长度。
- 开放定址的状态为 `EMPTY/OCCUPIED/DELETED`。探查至多 `m` 次；遇到 EMPTY 可以判定失败，遇到 DELETED 不能停止；复用墓碑前要完成重复键检查。主例不讨论另一类搬移重组删除实现。
- 课堂以**检查一次槽位计一次探查**；比较有效关键字的次数、CPU 运行时间及链表中结点比较次数不得混用。ASL 必须分别声明成功或失败查询的概率分布。
- 开放定址最坏可检查 `m` 个槽位，为 `O(m)`，只有在 `m=Θ(n)` 等明确关系下可化为 `O(n)`；链地址法最坏可能扫描 `n` 个记录。不能由同一个装载因子单独推出确定的 ASL；随机散列模型、装载因子控制与维护策略是常见期望效率保证的成立条件。重建触发的单次操作可能具有线性成本。

## 四、统一主例、反例和检验口径

主例：`m=7, h(k)=k%7`，依次插入 `10,17,24,13`。链地址：桶 3 为 10→17→24，桶 6 为 13；线性探查：位置 3、4、5、6 分别为 10、17、24、13。四个键**等概率成功查询**，成功 ASL 为 `(1+2+3+1)/4=7/4`（按槽位探查计）。

删除 17 后，位置 4 为 DELETED；查 24：`3→4→5`，成功；查 31：`3→4→5→6→0`，位置 0 为 EMPTY，失败、5 次探查。此时剩余 10、24、13 的**等概率成功 ASL** 为 `(1+3+1)/3=5/3`。再次插入 24 必须判定重复；插入新键 31 前先确认其不存在，随后可以复用位置 4。

失败 ASL 课堂模型：在删除前的初始线性探查表，对未命中的查询键假设其初始地址 0–6 等概率，失败探查次数按地址分别为 `(1,1,1,5,4,3,2)`，故 `ASL_unsucc=17/7`。这一概率空间与四个已有关键字等概率的成功 ASL 不同。

代价对照：`S1=(3,4,5,6)` 与 `S2=(3,10,17,24)`，同为 `m=7,alpha=4/7`，按给定顺序线性插入，均占据位置 3–6；**等概率成功 ASL** 分别为 1 与 2.5。最终占用形状相同不能代替探查路径与地址信息；在无墓碑的同占用状态下，两表对同一失败查询的探查长度相同。

课堂独立任务：P1 桶头/结点构造；P2 初次探查预测与 P3 余键独立构造；P4 错误 W 与正确 B 的因果解释、失败终止、去重与墓碑复用；P5 等概率失败 ASL，以及具体查询工作负载下的条件化结构选择。所有任务的输入与完成结构须在展开答案时可核对。

## 五、C11 示例与作业接口

`code/hash_demo.c` 为有限规模、无动态扩容的 **教学验证程序**。R6 以一份 C11 源码分别提供链地址法桶头/结点示范（`chain`）、线性探查逐步构造（`build`）、A/W/B/C 删除正确性对照（`scenarios`）、常规动态操作（`demo`）及全部主要状态和 ASL 的 `--self-test`。链地址使用固定结点数组与链式指针，避免把内存管理作为本讲主目标。

本地编译：`gcc -std=c11 -Wall -Wextra -Werror -pedantic code/hash_demo.c -o hash_demo`。运行 `./hash_demo chain`、`./hash_demo build`、`./hash_demo scenarios`、`./hash_demo demo` 和 `./hash_demo --self-test`。无需在仓库内执行，不要求 Git 提交。程序验证不了学生是否理解正确性。

**正式 A/B 作业以最后一页为唯一任务主源**：A 为教材第七章选择题 (12)(13)(14)、应用题 (5)，须写关键推理与构造过程；B 为先预测、再运行 C11 并解释错误删除 W、合法 B、墓碑查找、去重与复用。自学／选做应用题 (6)(7)、算法设计题 (6)，不默认提交。提交要求沿用课程 `course/assignments/homework-guide.md`，原则上附 3–5 行过程记录和飞书文档链接。

教材第七章 7.4.3 及对应习题原文已有此前按页复核：正文采用正负平方交替，应用题 (6) 指定正平方；选择题 (14) 表长 14、初址 `key%11`，应用题 (5) 地址 0–17、初址 `key%16`，不能把取模常数和数组容量混为一谈。**本周作业总负担及课堂时间仍由教师判断**。
