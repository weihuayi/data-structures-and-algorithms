# D013｜最小生成树与并查集

## 设计卡：本质关系

本讲由“搜索树可能多花钱”进入最低成本连接问题，再用教材 MST 性质与交换说明选边依据；Prim 保存当前区域与最便宜入口，Kruskal 按权扫描并合并分组，DSU 编码这些分组。主线是分别维护森林可行性与最优解可扩展性：无环不能替代最优性，父指针也不能替代已选图边。

**当前修订（2026-10-28，本地工作区）**：统一采用教材的 U 与 V-U，数学表达使用 LaTeX；F 始终表示已选边集合，用“保留全部顶点，只看已选边”说明相应森林，孤立顶点也保留；用连接两组顶点与保留已选边的直接说明代替补充术语。MST 性质与交换采用可见分区的大图分步演示；Prim 用同屏图、候选表和旧值/新值解释状态更新；增加 DSU 独立诊断；教材映射进入学生页面；全扫描明确区分 MST 已完成和剩余边核对；第 25 页并列两种等权 MST，第 30 页同图区分 MST 与最短路径。仍为 33 页，“先预测、再运行”并入第 28 页。修订与实际验证记录见 [REVISION.md](REVISION.md)。

依据：教材《数据结构（C语言版）（第3版）》6.1.2、6.6.1、算法 6.8/6.9、表 6.1；课程 Learning Progression 与 Matrix 的 D013 候选设计；本轮系统评审。教材定义按概述标注，教材图未复制。设计、测试与呈现证据不表示学生理解已经达成。

后续改进候选见 [教学主线分析与改进方案](IMPROVEMENT_PLAN.md)：重点为表示对算法的支撑、并查集的引入动机，以及分层的跨课程联系、页面改造与学习诊断。方案待实施与课堂验证，不改变本设计卡所记的当前页序、预算及作业范围。

## 接口方向与范围

- **D012**：搜索树保证覆盖可达点，但不保证最低总连接成本。回收分量、森林与辅助状态；Prim 的 key 是单条入口边权，parent 是候选来源，不能照搬搜索 parent 的语义。
- **D008、D010、D011**：回收森林边数、无环条件、交换论证、无向带权图与表示选择。
- **D014**：区分全网总边权与累计路径权；由 key 的含义引出最短路径状态问题。
- **范围**：排序作为既有接口；不展开堆优化 Prim 和反 Ackermann 证明。DSU 标为课程补充模型，不伪称教材逐字定义。

## 主案例、变式与独立任务

主例：A–E，AB=1、AC=4、BC=2、BD=5、CD=3、CE=6、DE=7；唯一 MST 为 AB、BC、CD、CE，总权 12。

| 案例 | 结果及作用 |
|---|---|
| Prim 从 A | 依次 AB、BC、CD、CE；接受 B 时 C 的入口 A:4→B:2，D 首次出现入口 B:5 |
| Prim 从 C | CB2、BA1、CD3、CE6；顺序变，总权仍 12 |
| Kruskal 主例 | 接受 AB、BC、CD，拒绝 AC、BD，接受 CE 时 MST 已完成；本讲全扫描继续拒绝 DE |
| 等权 CE=7 | 最后一条可选 CE 或 DE，总权 13；不同边权是唯一性的充分条件，不是必要条件 |
| 正式 B：DE=0 | Prim 为 AB、BC、CD、DE；Kruskal 接受 DE、AB、BC、CD；总权 6 |
| E 孤立 | 删除 CE、DE，两个分量、三条边、MSF 总权 6；孤立顶点也是树 |
| 负权/零权 | AB=−2、BC=0、AC=5，总权 −2；MST 算法允许负权，非负建设成本删环的建模理由有自身边界 |
| 第 9 页独立交换例 | AB=1、AC=2、BC=2；F={AB}，U={A,B}、V-U={C}，T={AB,BC}，e=AC，f=BC，T′={AB,AC}；两树总权均为 3 |
| 第 21 页压缩例 | 合并 AB、CD、BC 后 p[D]=C；find(D) 后 p[D]=A；划分与已选图边不变 |
| 第 22 页独立诊断 | p[A]=B、p[B]=B、p[C]=D、p[D]=B；A、C 同组，代表 B；find(C) 只把 p[C] 改为 B，划分与 F 不变 |
| 第 29 页独立机制应用 | P/Q/R/S；PQ3、PR1、QR2、QS4、RS5。接受 PR、QR，拒绝 PQ，接受 QS 时完成，总权 7；全扫描继续拒绝 RS；提前终止时 RS 应记未处理 |

## 安全边与状态模型

- **教材 MST 性质与交换**：把顶点分为非空的 U、V-U，取两组之间的最小权值边。为了保留已选边集合 F，说明已选边分别位于各组内部。若 e 不在包含 F 的 MST T 中，则 T+e 的环上还有另一条连接两组的边 f，且 f∉F；删 f 保留 F∪{e}，不增加总权。从空 F 开始保持可扩展性，直到已选边连通全部顶点并组成生成树。学生页面不额外定义“割”或“割尊重 F”，也不要求先理解 (V,F) 记号。
- **Kruskal 的两组顶点**：令 U 是包含候选端点 u 的当前分量，其余为 V-U；已选边不连接这两组。更轻的连接边若已处理，原本应被接受；早先拒绝的边两端也不会重新分开。排序和只合并共同支持轻边判断。
- **Prim**：`prim_states()` 仍为 9 个状态，新增只读 `key_changes`，记录外部点入口的旧值与新值。表中展示无入口顶点；仅在 has_key 为真时解释 key 的数值。接受边与候选更新发生在同一个接受状态。
- **Kruskal**：`kruskal_states()` 仍为 16 个状态，新增 `result_complete`。第 18 页展示排序条与当前扫描位置；接受 CE 后标记 MST 已完成，继续扫描 DE 仅作核对。C 与第 29 页采用同一全扫描口径。
- **DSU**：`parents()` 复制真实父指针，`components()` 用无压缩 root 只读观察；算法 find 可压缩，快照不会提前拍平父指针。F、划分、父指针分别保存。

## 图示、交互与教材对应

- 第 8 页两个顶点分组状态、第 9 页三个交换状态复用共享 `tree_trace.player`，无自动播放，上一步/下一步/重置与完成边界可检查。第 13、18 页继续使用原播放器。
- 共享图形支持显式背景 `regions` 和裁剪 `view_box`。区域只表达顶点集合，边仍来自输入图；区域位置不是自动生成的数学证明，需人工核对。第 20–22、29 页裁去无关空白以提高图内实际字号。
- 第 14、22、29 页复用共享答案工作区：输入图保持可见，折叠答案展开后替换右侧提问。无 JavaScript 时仍可读初态并使用原生折叠；打印保留当前播放器状态，打印分页仍需人工复核。
- 第 27 页把教材 `closedge.lowcost/adjvex` 对应到 `key/parent`；把 lowcost=0 的纳入标志对应到 used；以 present/weight 区分无边与零权，以 has_key 区分入口有无。
- 教材 Vexset 是分组编号，当前 DSU 用 find 求代表；直接 parent 不等不能推出不同组。Vexset 全表改号的代价不能套用 DSU 摊还结论。
- 第 26 页定义 n=|V|、m=|E|（教材用 e）。矩阵 Prim 为 O(n²)，边表 Kruskal 为 O(n+m log(m+1))，输入准备和空间另计；演示 Graph 同时保存矩阵和边表。DSU 高效依赖按大小合并与路径压缩，不把单次 find 宣称为保证 O(1)。
