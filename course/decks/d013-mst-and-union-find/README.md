# D013｜最小生成树与并查集

## 设计卡：本质关系

本讲从“遍历得到一棵树”推进到“构造过程中维护结构可行性与最优解的可扩展性”。Prim 维护已连接区域与每个外部顶点的最便宜入口；Kruskal 按权处理边，以当前连通分组决定是否合并。并查集保存的是动态等价关系，代表树是集合的一种表示，不是生成树边集。

课程主线接口为 ALG、INV、COR、JDG，以及表示—能力—代价—选择。重点区分两个问题：不成环保证结构合法；尊重当前森林的割上最轻边，保证选择仍可扩展到某个最优解。避免把“贪心”讲成记忆步骤或“每次最小所以总和最小”。

依据：课程认知主线 v0.2、Learning Progression Matrix v0.1 的 D013 条目；WhyOS `courses/why_data_structures_and_algorithms_structured_understanding_memo.md` 与 `why_course_engineering_structured_understanding_memo.md` v0.3。认知框架用于任务与评价设计，不直接作为学生需背诵的形式化理论。资产完成不代表学习效果已经验证。

## 主例与边界

主例顶点 A–E，边 AB1、AC4、BC2、BD5、CD3、CE6、DE7。Prim 从 A 依次选 AB、BC、CD、CE；Kruskal 按权依次接受 AB、BC、CD，跳过 AC、BD，接受 CE。总权 12。

- **从 C 开始的补全**：CB2、BA1、CD3、CE6；选边顺序改变，最优总权不变。
- **等权**：CE 改为 7，最后可选 CE 或 DE，总权 13。等权不必然造成多解，但本例有两解。
- **正式 B 变式**：DE 改为 0。Prim 顺序 AB、BC、CD、DE；Kruskal 顺序 DE、AB、BC、CD；总权 6。
- **非连通**：删 CE、DE，E 孤立。返回两个分量的最小生成森林，总权 6；不得报告为覆盖全部顶点的 MST。
- **负权算法边界**：AB=-2、BC=0、AC=5，MST 总权 -2。MST 算法无需非负权；但主例“删环不会增加连接成本”的物理建模理由只对非负建设成本成立。
- **独立任务**：P–S，PQ4、PR1、QR2、QS1、RS5。选 PR、QS、QR，总权 4；要求分组与一次割的理由。

## 实现与结论边界

- 输入限 1–16 个顶点的简单无向图，整数权在 [-1000000,1000000]。拒绝空顶点集、超容量、越界、自环、重复或反向重复边；失败清空输出。所有内部指针要求有效，算法只接受成功构造且过程中不修改的图。
- `present` 与 `weight` 分离，零权不是无边；`has_key` 与 key 分离，不借有限“无穷大”哨兵排除合法权。限制顶点与权值使 `long long` 总权不会溢出。
- Prim 每轮扫描候选与矩阵行，Θ(n²)；无候选时从尚未处理的顶点重启，显式返回森林分量数。非连通图不存在单棵覆盖全图的 MST。
- Kruskal 用归并排序按权、端点编号确定次序；排序 O(m log m)，辅助数组 O(m)，并查集与结果 O(n)。孤立点初始化 O(n) 不能遗漏。排序的平局策略只为复现，不代表唯一答案。
- 并查集按大小合并，路径压缩保持分组不变；size 仅对根有效。其摊还复杂度是操作序列结论，不能说每次 find 保证常数时间。
- 两算法都支持负权的 MST/MSF 问题；含负权时，不推广到允许任意多余边的最低成本连通子图。
- `verify` 检查结果边有效、无环、覆盖原图的每个连通分量、边数与总权一致；它自身不证明权值最优。
- 内置检查覆盖单顶点、非法构图、负权满容量链、合并与路径压缩。不要定义 NDEBUG 后声称断言已经运行。
