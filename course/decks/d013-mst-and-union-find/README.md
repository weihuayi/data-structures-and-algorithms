# D013｜最小生成树与并查集

## 设计卡：本质关系

本讲从“搜索树可能多花钱”进入最低成本连接问题，用教材 MST 性质与交换论证支撑安全选择，再连接算法需要的访问、状态与维护机制。Prim 通过输入图的邻接信息更新每个外部点的最佳入口；Kruskal 先把已有表示整理为不重复的边数组，再按权扫描。并查集从当前选边上的重复连通查询中产生，经教材分组编号过渡到父指针表示。

**当前修订（2026-10-28）**：已实施[主线改进方案](IMPROVEMENT_PLAN.md)，课件为 **41 页**；预算仍为 **90 分钟**。补齐两条主线，增加表示与更新、代价与条件的独立诊断；保留安全选择证明、DSU 诊断、7+2 分钟新网络练习及既有正式作业。以稀疏矩阵按行计算作为课堂主要跨课程联系，环与线性相关放在课后探索层。实际修订及验证见 [REVISION.md](REVISION.md)；资产检查不表示学习效果已经验证。

依据：教材《数据结构（C语言版）（第3版）》6.1.2、6.6.1、算法 6.8/6.9、表 6.1；D011/D012；课程 Learning Progression 与 Matrix 的候选设计；教师提出的主线与迁移需求。教材定义按概述标注，图示自行绘制。学生页面统一用教材的 U、V-U；F 始终表示已选边集合。森林直接说明为“保留全部顶点，只看已选边”，包含孤立顶点，不额外引入补充术语。

## 接口方向与范围

- **D004**：同一组查询、合并操作可有不同实现；先明确 ADT，再比较表示及代价。
- **D008、D010**：回收森林边数、无环条件、交换论证及排序接口。
- **D011 → D013**：从图 ADT 的 neighbors、矩阵行、邻接项和存在性判断，过渡到算法实际读取的输入。图存储不自动包含 key、used 或动态分组。
- **D012 → D013**：搜索树不保证最低总连接成本；DFS/BFS 可判断当前选边是否已连通两个端点，重复查询进一步产生保存分组的需求。
- **D013 → D014**：Prim 的 key 是单条入口边权；最短路径需要累计路径权。后续优先队列回应高效取最小及更新候选的问题。
- **跨课程及用途**：比较邻接表与稀疏矩阵行访问；说明零系数与零权边的语义差别。若已学线性相关，可课后探索关联矩阵。用断线图讨论模型约束，避免从数学最优直接推出真实用途适用。
- **实现范围**：排序作为已有接口；不展开堆 Prim、反 Ackermann 证明、CSR 或其他网络优化算法。C 演示保持同时存矩阵和边数组，未实现邻接链表，不把算法与表示一一绑定。

## 主案例、变式与独立任务

主例：A–E，AB=1、AC=4、BC=2、BD=5、CD=3、CE=6、DE=7；唯一 MST 为 AB、BC、CD、CE，总权 12。

| 案例 | 结果及作用 |
|---|---|
| Prim 从 A（12–15） | 依次 AB、BC、CD、CE；读 B 行或 B 的三条邻接记录后，C 的入口 AC:4→BC:2，D 首次有 BD:5，E 仍无入口 |
| Prim 从 C（16） | CB2、BA1、CD3、CE6；顺序变，总权仍 12 |
| Kruskal 主例（19–22） | 两种表示提取同一七边数组；接受 AB、BC、CD，拒绝 AC、BD，接受 CE 时 MST 完成；全扫描继续拒绝 DE |
| Vexset（23） | 接受 CD 时，把 D 的组号 3 改成 0；编号直接查询，合并需扫描改号 |
| 合并根及压缩（25、27） | 独立例先合并 AB、CD，再合并 BC；只令 p[C]=A，D 仍指向 C；find(D) 后 p[D]=A，划分不变 |
| DSU 独立诊断（28） | p[A]=B、p[B]=B、p[C]=D、p[D]=B；A/C 代表均为 B；压缩只改 p[C]，不改变划分或 F |
| 等权 CE=7（30） | 最后一条可选 CE 或 DE，总权 13；同图并列两种 MST |
| 正式 B：DE=0 | Prim 接受 AB、BC、CD、DE；Kruskal 接受 DE、AB、BC、CD；总权 6 |
| E 孤立（17） | 删除 CE、DE，两个分量、三条边、MSF 总权 6；孤立顶点也是树 |
| 负权/零权 | AB=−2、BC=0、AC=5，总权 −2；MST 算法允许负权，非负建设成本删环的建模理由有自身边界 |
| 独立交换例（9） | AB=1、AC=2、BC=2；F={AB}，T={AB,BC}，e=AC，f=BC，T′={AB,AC}；总权均为 3 |
| 独立机制应用（35） | P/Q/R/S；PQ3、PR1、QR2、QS4、RS5。接受 PR、QR，拒绝 PQ，接受 QS 时完成，总权 7；全扫描拒绝 RS，提前停止则 RS 未处理 |
| 用途变化（38） | 原 MST 的 CE 故障，E 断开；新增任一线路故障仍连通的要求，必须重新定义可行方案 |

## 状态、图示与实现约定

- **教材 MST 性质与交换**：U、V-U 非空，已选边分别位于组内。取两组间最小权边 e；若 e 不在包含 F 的 MST T 中，T+e 的环上还有连接两组的边 f，且 f 不属于 F。删 f 保留 F∪{e}，不增总权；从空集开始保持可扩展性，直到连通全部顶点并组成树。
- **Prim**：9 个确定状态。key_changes 只在接受新顶点或重启分量时记录旧/新入口；input_row 保存对应顶点的逻辑输入行，候选选择阶段为空，避免把选择候选与扫描输入混为同一操作。无边用 None/—，零权保留；has_key 区分入口有无。
- **Kruskal**：16 个状态。图上红粗边已接受、橙虚线正在检查、灰细虚线已拒绝；排序条和 result_complete 区分 MST 完成与全扫描结束。父指针不提前进入首次算法演示。
- **DSU**：同一 find/union 接口可用分组编号或父指针实现；合并根的前后快照来自真实操作。parents/components 是只读观察，不触发压缩；find 可压缩。已选图边、分组划分和父指针分别保存。
- **表示转换**：第 19 页两种输入视图和输出边数组来自 MAIN_EDGES；无向简单图按端点编号保留一次，排序副本不改输入。提取代价与已有边数组上的扫描代价分别说明。
- **复杂度**：n=|V|、m=|E|，排序按 O(m log(m+1)) 计；全表改号至多 n−1 次扫描，优化父指针的代价依赖按大小合并与路径压缩。不把单次 find 宣称为保证 O(1)。当前 C 的矩阵空间不能用边扫描阶段的线性空间代替。
- **交互**：第 8、9、19 页关系演示与第 15、21 页算法演示复用共享播放器；第 13、16、28、32、35、38 页保留必要输入并折叠答案。教师注记未重新加入。无 JavaScript 时初态静态可读；打印和连续阅读不等同于完整课后解答导出。
