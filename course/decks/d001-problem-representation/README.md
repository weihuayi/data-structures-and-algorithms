# D001｜从问题到计算表示与程序

## 本质关系

问题到程序的完整链条：对象与信息 → 计算表示 → 条件 → 程序 → 运行检查。表示是一种选择——保留什么信息，决定了能算什么、算得多快；"程序能运行"不等于"程序正确"，运行之后还要检查。这条链条是全学期每个结构的默认叙事骨架。

## 接口方向

- **教材锚点**：第 1 章绪论（数据、数据结构、逻辑结构与存储结构；术语的正式锚定在 D002）。
- **生活连接**：商品凑单（两件恰好 32 元）、迷宫寻路。
- **工程接口**：迷宫 → AGV 智能工厂调度（教师注记）；几千台 AGV 与小迷宫同构。
- **计算机接口**：C 程序从源码到运行的完整过程（编译、改源码须重新编译）。
- **实践种子**：迷宫 → AGV 路径规划类项目；配对 → 数据组织类项目（D002 直接续讲）。
- **预留回收**：D002 在同一配对案例上继续追问"数据多了怎么办"；D011 图再回到迷宫。

## 主要教学目标

从熟悉的现实问题出发，让学生经历“对象与信息 → 计算表示 → 条件 → 程序 → 运行与检查”的完整过程，并把课程学习重新连接到理解、表达、实践与判断。

## 主要问题

- 一个问题中的对象、信息和关系怎样表达给计算机？
- 数学条件怎样约束合法候选，并怎样对应到程序结构？
- 程序能够运行以后，还需要检查什么？

## 主要案例

迷宫、商品金额配对。
