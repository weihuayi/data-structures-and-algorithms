# D016｜查找：有序信息怎样减少比较？

## 设计卡与内容边界

依据三轮讨论和压力测试形成首稿。五阶段为：明确任务 → 利用有序信息 → 计算代价 → 分块索引迁移 → 结合需求选择。当前 34 页是页面职责的表达结果，后续按输入在场与可读性拆分；不从页数换算授课时长。当前没有本讲实际课堂运行、用时或学生达成证据。

主要认知变化：在 D002 已接触的批量排除思想上，建立明确的查找契约、可靠的候选更新与终止依据，按计数和概率评价查找，再结合表示及维护成本选择方法。

- 必须理解：记录/关键字/下标；成功与失败；顺序基线；折半的同字段有序性、闭区间与推进；判定树及成功/失败 ASL 的条件；块间范围与块内扫描；准备和维护的取舍。
- 默认实现：0 起数组下标，顺序从前向后；折半闭区间、向下取中点，命中返回任一匹配下标、失败返回 −1。主例互异，重复键只作返回要求的边界；不宣称返回第一项。
- 主线外：哨兵技巧的完整展开、特殊长度 ASL 公式推导、动态分块维护、首/末匹配变式。它们由教材导航或后续实践深化；BST/AVL、散列、排序分别归 D017–D020。
- 教学表示：数组输入全程保留；比较、更新、命中与空区间失败分开。答案呈现更新后的区间、判定树或索引过程，不只给结果文字。

## 主例、计数与可核对结果

关键字：5、16、20、27、30、36、44、55、60、67、71。表示商品编号，其他字段与记录身份一同保留，图中仅展示关键字。

一次对一个记录关键字作大小/相等判定计 1 个；不把 C 的关系运算次数、数组访问、记录移动和实测时间混成同一量。程序计数在读取候选记录时增加一次。演示轨迹的存储不计入无日志核心迭代的 O(1) 辅助空间结论。

| 对象 | 结果与条件 |
| --- | --- |
| 顺序查 27 | 比较 5、16、20、27，返回 3，计 4 |
| 顺序查 65 | 遍历全部 11 条，返回 −1；不利用有序性提前停止 |
| 折半查 27 | 36、20、27，返回 3，计 3 |
| 折半查 65 | 36、60、67，low=9、high=8，返回 −1，计 3 |
| 折半查 71 | 36、60、67、71，返回 10，计 4 |
| 成功比较次数 | 3、4、2、3、4、1、3、4、2、3、4 |
| 成功等概率 | 顺序 ASL=6，折半 ASL=3，折半最坏比较 4 |
| 查 5 概率 0.8，其余各 0.02 | 只在成功查询中加权，顺序 ASL=2.1，折半=3 |
| 失败间隙代表键 | 4、10、18、23、28、33、40、49、57、63、69、72 |
| 代表键比较次数 | 3、4、4、3、4、4、3、4、4、3、4、4 |
| 失败间隙等概率 | 失败 ASL=44/12=11/3；不是由成功等概率推得 |
| 新表 8、19、31、47 | 折半成功次数 2、1、2、3；等概率均值 2，顺序 2.5 |
| 分块 30 / 28 | 分别命中下标 5 / 返回 −1；均索引比较 2、记录比较 3 |
| 查询成本题 | 题设统一以比较次数计，准备 60；6q 与 60+3q，q>20 才有比较次数收益 |

分块仍使用原 11 个关键字：B1=(16,5,20)、B2=(36,27,30)、B3=(44,71,55,67,60)。最大关键字为 (20,36,71)，起始下标 (0,3,6)，末下标 (2,5,10)。索引先选首个最大关键字 ≥ 目标的块，块内逐个检查，不根据大小提前结束。

## 压力测试边界

1. 折半按同一关键字、同一比较规则非递减；主例互异不是二分查找的一般必要条件。
2. 闭区间 low≤high；未命中排除中点，low=mid+1 或 high=mid−1。空表不读元素；下标 0 是合法命中。
3. ASL 的计数、成功/失败和概率分别声明。任意长度不套用特殊满树闭式公式；混合查询还需发生比例。
4. 本讲对数时间对应数组 O(1) 随机访问；链表走访不被比较次数隐去。
5. 分块满足 max(前块)<min(后块)，不能只看索引最大值递增。非法分块 (5,30)/(16,36) 查 16 是反例。
6. 块内无序不推得 O(1) 更新；移动、容量与索引维护另计。查找例程不每次扫描验证有序性；构建/维护承担前提。

~~~
