# D007｜串与模式匹配

## 本质关系

串 = 内容受限的线性表（数据元素是字符），是第 2 章线性表体系的第一个特例回收。模式匹配的本质链：BF 失配时把"已匹配的信息"全部丢弃、主串指针回溯——浪费的不只是时间，是信息；KMP 的核心是**已匹配的信息不浪费**：失配时主串指针 i 不回头，模式指针 j 退到 next[j]，而 next[j] 只由模式自身的结构（最大相等前后缀长度 = 模式的自相似性）决定，与主串无关；求 next 本身又是一次模式匹配——模式在跟自己匹配，一次自举。代价对照：BF 最坏 O(n·m) vs KMP O(n+m)，用对模式的一次预处理换主串的一遍过。可迁移的原则：失配携带信息，不是纯粹的失败；已经知道的东西，不要花代价再知道一次。

## 主要教学目标

- 能说出串是内容受限的线性表，说清子串、主串、位置的概念；
- 能手工模拟 BF 匹配（i、j 指针轨迹），指出失配时浪费掉的信息是什么；
- 能手算 next 数组（最大相等前后缀长度），并用它手工模拟 KMP，说出 i 为什么可以不回头；
- 能解释 next[j] 只依赖模式自身，知道求 next 是模式与自身的匹配；
- 知道串的三种存储结构及其适用边界；能对 DNA 案例说出"环形模式 → 倍长复制"的问题转化。

## 主要问题

- 在一篇文章里找一个词，你会怎么找？（回收 D006 留问）
- 失配了，刚才比对出来的信息就这么扔掉吗？
- 主串指针不回头，模式指针该退到哪里？谁说了算？
- next[j] 为什么只跟模式有关，跟主串无关？求 next 是不是模式在跟自己匹配？
- 病毒 DNA 是环状的，怎么办？

## 主要案例

**主案例：教材案例 4.1 植物双生病毒 DNA 检测（已核对教材）**：4.2 引入（苹果双生病毒 AGV、桑花叶萎缩相关病毒 MMDaV）→ 模式匹配建模 → 4.6 实现亮点"环形序列倍长复制"（病毒 DNA 存两遍，循环取 m 个起点各做一次匹配）——问题转化比算法本身更值得讲。手工推演两例均取自教材：BF 的浪费用 S="abcdefghi"、T="abcdx"（前 4 字符全等、第 5 个失配后四趟重来，直观暴露浪费，也恰好说明模式无重复时 KMP 退化为"j 回开头"）；KMP 的 next 表用 T="abaabc"（next = 0,1,1,2,2,3）。演示代码计划：`match_demo.c`——同一组 S、T 上跑 BF 与 KMP，打印各自字符比较次数，先预测再运行。
