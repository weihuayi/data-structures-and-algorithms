# 共享课件工具协作约定

继承[仓库入口](../../AGENTS.md)。当前 API 与命令见[本目录说明](README.md)，教学约束见[课程共性](../../docs/design/deck-contract.md)。

- 内容与案例留在课件，稳定的表达和验证能力进入共享层；复用现有图示、播放器及构建器，保持旧三元组和未迁移课件可构建。
- 修改公共组件时，同步 API 说明、可运行样例及采用者生成物；按实际依赖回归。未知共享影响保守扩大，不能静默选中零对象。
- 独立检查学习任务要求的结果，不能只把同一生成函数作为自身唯一预期。结构图应检查实际顶点、边与方向；检查器增加有意义的正常与故障夹具。
- 约定文件和目录 AGENTS 纳入影响分析、CI 触发与依赖指纹。入口应可发现、链接有效，正文唯一维护，避免在多个目录复制完整规范。
- 机器报告如实区分通过、失败、不完整、默认页和完整操作；保留原始失败及覆盖边界。不能放宽规则、更新基准或删掉故障用例来掩盖问题。
- 交付记录检查版本、覆盖声明和未决发现，不能据此证明 AI 理解规则、教师完成审阅或学生已经掌握。
- 工具修改完成后运行必要单元测试、检查器故障回归和影响对象的系统检查，并依照[课件完成验收](../../course/decks/AGENTS.md)执行 AI 内容/视觉自审、修订与复查。
