# 数据结构与算法

本仓库同时承载课程教学、学生学习实践与真实项目开发。

## 三条主要入口

- **课程学习**：进入 [`course/`](course/) 查看教学课件、讲义与任务定义。
- **公开作业提交**：进入 [`submissions/`](submissions/) 查看适合公开 PR 的提交边界与路径约定。
- **项目实践**：根据具体项目任务进入 `src/`、`tests/`、`docs/`、`examples/` 等工程目录。

课程教学内容不按自然周或固定课时组织。稳定教学课件以 Deck 为主要维护对象；某一学期实际推进到哪里，由 `course/offerings/` 记录。
