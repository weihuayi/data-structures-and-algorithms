# Submissions

本目录只承载**适合公开进入主仓库**的学生课程学习提交，不是所有课程评价材料的统一提交池。

建议路径：

```text
submissions/<offering>/<assignment>/<public-student-id>/
```

例如：

```text
submissions/2026-fall/a01/s023/
```

普通公开 Submission PR 原则上只修改自己的提交目录。编译产物、IDE 目录、压缩包、大体积截图和视频不应进入本目录。需要独立评价、公开答案会削弱评价意义的任务，应使用私有提交方式；真实项目贡献直接针对 `src/`、`tests/`、`docs/`、`examples/` 等共同工程对象提交 PR。
